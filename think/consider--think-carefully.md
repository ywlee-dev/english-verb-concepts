# CONSIDER — think carefully before choosing

## 0. Sound & Forms

- **Pronunciation (US):** /kənˈsɪd.ər/ [컨**시**더] — 뒤 음절 강세다.
- **Forms:** `consider` — `considered` — `considered`; 규칙 변화다.
- **시제와 결과:** `The class considered each plan during the meeting.` → `The class has considered both plans. They know the pros and cons of each now.` 신중히 검토한 사건과 현재의 비교된 지식 상태를 구별한다.

- **Sense:** 결정하기 전에 TARGET의 여러 면과 영향을 주의 깊게 생각하다.
- **Example:** `The class considered each plan.`
- **Target Condition:** 장단점이나 결과를 비교할 수 있는 선택안·요청·가능성
- **Precondition:** 둘 이상의 선택이나 고려해야 할 영향이 있다.

## 언제 이 말을 꺼낼까?

창가 쉼터와 복도 쉼터 모두 장점이 있다. 공간·비용·소음을 항목별로 따져 본다. **선택 전에 여러 면을 신중히 살피면** `consider`다.

- **TARGET:** 장단점이나 영향을 검토할 수 있는 선택안·요청·가능성.
- **BASIC/RESULT + HOW:** 생각이 이루어짐 + **여러 관련 면을 검토하는** 방식. 선택이 끝났다는 뜻은 아니다.
- **선택 경계:** `think about`은 넓은 생각; `consider`는 선택안을 진지하게 검토한다.
- **한 문장:** `We considered each plan.`
- **내 장면:** 구매나 일정 선택 전에 따져 본 조건을 떠올려 보자.

## Scene Scenario
- **PLACE:** 학급 회의 시간
- **SITUATION / PROBLEM:** 창가 쉼터와 복도 쉼터 모두 장점이 있지만 공간과 소음 조건이 다르다.
- **PURPOSE:** 성급하지 않게 더 나은 계획을 고른다.
- **WHY THIS HOW?:** 아이디어를 떠올리는 단계보다 각 안의 결과를 비교 검토하는 단계이므로 `CONSIDER`가 적합하다.
- **ACTION → RESULT:** 학생들이 공간·비용·소음을 항목별로 살펴 각 계획의 장단점을 안다.

```text
THINK + 결정 전 여러 면을 신중히 검토 = CONSIDER
```

## Minimal Contrast

문제를 넓게 `think about`할 수 있지만, 실제 후보를 선택 전에 따져 볼 때 `consider`한다.
