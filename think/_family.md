# THINK Family

## Shared Result

agent가 머릿속에서 정보와 가능성을 다루어 판단·생각·선택을 형성한다.

| Verb | Example | Distinctive Mental HOW |
|---|---|---|
| THINK | think about the problem | 생각을 머릿속에서 다룸 |
| CONSIDER | consider each plan | 선택 전에 여러 면을 살핌 |
| IMAGINE | imagine a tree house | 실제로 없는 장면을 마음속에 만듦 |
| GUESS | guess the answer | 정보가 부족한 상태에서 답을 고름 |
| DECIDE | decide on the blue plan | 생각을 끝내고 선택을 확정 |

## Scenario contrast

학급 쉼터 문제를 머릿속으로 다루면 THINK, 각 계획의 장단점을 따지면 CONSIDER, 완성 모습을 그려 보면 IMAGINE, 자료 없이 비용을 짐작하면 GUESS, 최종 계획을 확정하면 DECIDE가 된다.

## 상황에서 꺼내기 — 설명을 보기 전에

학급 쉼터를 만들고 싶다. **지금 머릿속에서 무슨 일이 일어나는가?**

1. 어떻게 만들지 넓게 생각한다. 아직 답이나 선택은 없다.
2. 창가와 복도 계획의 공간·비용·소음을 신중히 비교한다.
3. 아직 없는 나무 모양 독서 공간의 완성 모습을 마음속에 그린다.
4. 가격을 조사하지 못했지만 방석 비용을 임시로 짐작한다.
5. 두 계획 중 창가 계획을 최종 선택한다.

<details><summary>동사와 선택 이유 보기</summary>

1. `We thought about the problem.` — 생각하는 과정, 결론은 열려 있다.
2. `We considered each plan.` — 선택 전에 여러 면을 검토한다.
3. `We imagined a tree-shaped reading corner.` — 없는 장면을 마음속에 만든다.
4. `We guessed the cost of the cushions.` — 정보가 부족한 상태에서 가능한 값을 말한다.
5. `We decided on the window plan.` — 선택이 확정된다. 실제 시공은 아직이다.

</details>
