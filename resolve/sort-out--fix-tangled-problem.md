# SORT OUT — fix a tangled problem

## 0. Sound & Forms

- **Pronunciation (US):** /sɔːrt aʊt/ [소트**아웃**] — 구동사이며 뒤 단어 `out`에 강세가 있다.
- **Forms:** `sort out` — `sorted out` — `sorted out`; `sort`만 바뀌고 `out`은 그대로다. 대명사는 가운데: `sort it out` (`sort out it` ✗).
- **시제와 결과:** `Mina and Jin sorted out the mix-up on Thursday night.` → `They have sorted out the mix-up. The calendar and the notice show the same time now.` 고치는 일을 한 사건과 지금 일정이 맞아 있는 상태를 구별한다.

- **Sense:** 꼬이거나 엉망이 된 문제를 하나씩 손봐서 바로잡다. 구어적이다.
- **Example:** `Mina and Jin sorted out the mix-up.`
- **Target Condition:** 여러 조각이 엉켜 있어 손을 대 정리할 수 있는 문제·일정·서류·갈등
- **Precondition:** 무엇이 꼬였는지 볼 수 있고 직접 고칠 수 있다.

## 언제 이 말을 꺼낼까?

모임 시간이 단체 대화방 공지에는 7시, 공유 달력에는 8시, 예약한 스터디룸은 7시 반으로 제각각이다. Mina와 Jin이 하나씩 확인하며 고친다. **꼬인 것을 손봐서 제자리로 정리하면** `sort out`이다.

- **TARGET:** problem, mess, mix-up, schedule, paperwork처럼 손댈 수 있는 꼬인 일. 사람 사이 문제도 된다(`sort things out with Jin`).
- **BASIC/RESULT + HOW:** 문제가 정리되어 끝남 + **조각을 하나씩 손봐 제자리로 놓는** 방식. `sort`는 원래 "종류별로 가르다"라서 "골라 제자리에"라는 그림이 남아 있다.
- **선택 경계:** 같은 결과를 격식 있게 말하면 `resolve`. 오해 하나만 걷으면 되면 `clear up`. `It'll sort itself out.`은 손대지 않아도 저절로 정리된다는 말이다. 영국 영어에서 특히 흔하고, 미국 영어에서는 `work out`, `straighten out`, `figure out`도 많이 쓴다.
- **한 문장:** `Don't worry, we sorted it out.`
- **내 장면:** 꼬인 예약이나 서류를 하나씩 고쳐 바로잡은 일을 떠올려 보자.

## Scene Scenario

- **PLACE:** 목요일 밤, 둘이 노트북 앞에서 화상 통화
- **SITUATION / PROBLEM:** 공지·달력·스터디룸 예약이 서로 다른 시간을 가리켜 회원들이 묻는 메시지가 쌓인다.
- **PURPOSE:** 모든 곳이 같은 시간을 가리키게 정리한다.
- **WHY THIS HOW?:** 결론을 선언하는 것이 아니라 꼬인 조각을 하나씩 손봐 정리하는 일이 중심이고, 친구 사이 말이므로 `SORT OUT`이다.
- **ACTION → RESULT:** 공지를 고치고, 달력을 바꾸고, 예약 시간을 옮긴다. 이제 어디를 봐도 7시 반이다.

```text
RESOLVE + 꼬인 조각을 손봐서 제자리로 정리 (구어) = SORT OUT
```

## Minimal Contrast

회원에게 결과를 공지하며 `The issue has been resolved.`, 친구에게 말할 때는 `We sorted it out.`이다.
