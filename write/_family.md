# WRITE Family

## Shared Result

agent가 언어적 내용을 문자로 만들어 종이·화면 등에 남긴다. `SAY`는 소리로 표현하고 `WRITE`는 다시 볼 수 있는 글로 남긴다.

| Verb | Same-target example | Distinctive HOW |
|---|---|---|
| WRITE | write a message | 글로 남기는 방식 미지정 |
| JOT DOWN | jot down a message | 빠르게 짧게 적음 |
| DRAFT | draft a message | 최종본 전 초안을 만듦 |
| TYPE | type a message | 키보드로 입력 |
| COMPOSE | compose a message | 표현·구조를 생각하며 내용을 지음 |

## Scenario contrast

친구에게 남길 글을 만들면 WRITE, 잊기 전에 짧게 적으면 JOT DOWN, 고칠 것을 전제로 초안을 만들면 DRAFT, 키보드로 입력하면 TYPE, 문장과 순서를 고민해 지으면 COMPOSE이다.

## 상황에서 꺼내기 — 설명을 보기 전에

누군가에게 남길 글이 있다. **글을 만드는 목적과 방식**을 골라 보자.

1. 친구가 나중에 보도록 과제 변경 내용을 글로 남긴다.
2. 선생님이 말한 새 페이지 번호를 잊기 전에 공책에 급히 적는다.
3. 선생님에게 보낼 결석 안내를 고칠 생각으로 첫 버전부터 만든다.
4. 컴퓨터실에서 키보드를 눌러 메시지를 화면에 입력한다.
5. 생일 카드에 추억·축하·바람을 어떤 순서로 쓸지 고민해 글을 짓는다.

<details><summary>동사와 선택 이유 보기</summary>

1. `I wrote a message to Jin.` — 말이 아닌 글로 남긴다.
2. `I jotted down the new page number.` — 빠르고 짧은 기록이다.
3. `I drafted a message to the teacher.` — 수정 가능한 초안이다.
4. `I typed a message on the laptop.` — 키보드 입력 방식이다.
5. `I composed a birthday message.` — 표현과 구성을 생각해 내용을 짓는다.

</details>
