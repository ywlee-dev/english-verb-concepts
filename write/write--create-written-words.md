# WRITE — create written words

## 0. Sound & Forms

- **Pronunciation (US):** /raɪt/ [**라**이트] — 단음절이며 `right/rite`와 발음이 같다.
- **Forms:** `write` — `wrote` — `written`; 불규칙이며 세 형태가 모두 다르다.
- **시제와 결과:** `Mina wrote a message to Jin after school.` → `Mina has written the message. Jin can read it on his desk now.` 적은 사건과 현재 남아 있는 글의 상태를 구별한다.

- **Sense:** 말이나 생각을 문자로 표현해 남기다.
- **Example:** `Mina wrote a message to Jin.`
- **Target Condition:** 문자와 문장으로 표현할 수 있는 정보·생각·요청
- **Precondition:** agent에게 전할 내용과 글을 남길 매체가 있다.

## 언제 이 말을 꺼낼까?

Jin이 먼저 집에 가서 과제 변경을 말로 전할 수 없다. 종이에 새 과제 내용을 적어 책상에 둔다. **말이 아닌 글을 남기면** `write`다.

- **TARGET:** 문자로 표현해 남길 수 있는 정보·생각·메시지.
- **BASIC/RESULT + HOW:** 다시 볼 수 있는 글이 생김 + **언어를 문자로 표현하는** 방식. 펜인지 키보드인지는 열려 있다.
- **이 말을 고르는 이유:** 지금 듣는 사람에게 말하면 `say`; 나중에 읽을 수 있게 남기면 `write`다.
- **한 문장:** `I wrote a message to Jin.`
- **내 장면:** 오늘 남긴 메시지나 메모 하나를 넣어 말해 보자.

## Scene Scenario
- **PLACE:** 방과 후 교실 책상
- **SITUATION / PROBLEM:** Jin은 먼저 집에 갔고 Mina는 과제 변경을 알려야 한다.
- **PURPOSE:** Jin이 나중에 볼 수 있는 정보를 남긴다.
- **WHY THIS HOW?:** 말로 즉시 전하는 것이 아니라 문자를 남기는 결과가 중요하므로 `WRITE`를 쓴다.
- **ACTION → RESULT:** Mina가 종이에 새 과제 내용을 문장으로 적어 Jin의 책상에 둔다.

```text
BEFORE: 생각만 있음 → HOW: 문자를 배열 → AFTER: 다시 읽을 수 있는 글이 남음
```

## Minimal Contrast

지금 듣는 사람에게 말하면 `say`, 나중에 볼 수 있도록 글로 남기면 `write`한다.
