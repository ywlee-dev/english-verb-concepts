# COMPOSE — create carefully structured text

## 0. Sound & Forms

- **Pronunciation (US):** /kəmˈpoʊz/ [컴**포**우즈] — 뒤 음절 강세다.
- **Forms:** `compose` — `composed` — `composed`; 규칙 변화다.
- **시제와 결과:** `Mina composed a thoughtful message to Jin the night before his birthday.` → `Mina has composed the message. The card now holds her full message.` 내용을 지은 동작과 현재 완성된 카드 상태를 구별한다.

- **Sense:** 내용·표현·순서를 생각하며 글이나 메시지를 짓다.
- **Example:** `Mina composed a thoughtful message to Jin.`
- **Target Condition:** 단순 기록보다 문장 선택과 구조가 중요한 글
- **Precondition:** 전달할 생각이 있고 읽는 사람에게 맞는 표현을 골라야 한다.

## 언제 이 말을 꺼낼까?

친구 생일 카드에 평범한 한 줄 대신 추억, 축하, 바람을 담고 싶다. 문장과 순서를 고민해 메시지를 짓는다. **내용을 구성해 만들어 내는 일**이 중심이면 `compose`다.

- **TARGET:** 표현과 구조를 생각해 지을 수 있는 메시지·편지·글.
- **BASIC/RESULT + HOW:** 글의 내용이 생김 + **문장과 순서를 의도적으로 구성하는** 방식. 키보드인지 펜인지는 핵심이 아니다.
- **이 말을 고르는 이유:** 남의 말을 그대로 적으면 `write`가 중립적이다. 마음을 담아 표현을 골라 지으면 `compose`가 맞는다.
- **한 문장:** `I composed a birthday message for Jin.`
- **내 장면:** 표현을 골라 쓴 카드나 글을 떠올려 문장을 만들어 보자.

## Scene Scenario
- **PLACE:** 친구의 생일 전날 집 책상
- **SITUATION / PROBLEM:** Mina는 축하 카드에 진심을 담고 싶지만 평범한 한 줄로는 부족하다.
- **PURPOSE:** 경험과 감정을 순서 있게 담은 메시지를 만든다.
- **WHY THIS HOW?:** 문자를 단순히 적는 것보다 내용과 구조를 지어 내는 과정이 중요하므로 `COMPOSE`를 쓴다.
- **ACTION → RESULT:** Mina가 추억, 축하, 바람 순서로 문장을 고쳐 카드 메시지를 완성한다.

```text
WRITE + 내용·표현·구조를 의도적으로 설계 = COMPOSE
```

## Minimal Contrast

말을 그대로 받아 적으면 `write`, 표현을 골라 새로운 글을 지으면 `compose`한다.
