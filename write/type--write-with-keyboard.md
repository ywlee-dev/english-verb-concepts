# TYPE — write with a keyboard

## 0. Sound & Forms

- **Pronunciation (US):** /taɪp/ [**타**입] — 단음절이다.
- **Forms:** `type` — `typed` — `typed`; 규칙 변화다.
- **시제와 결과:** `Mina typed a message on the laptop in the computer room.` → `Mina has typed the message. It appears on the screen now.` 입력한 동작과 현재의 화면 표시 상태를 구별한다.

- **Sense:** 키보드의 글쇠를 눌러 문자를 입력하다.
- **Example:** `Mina typed a message on the laptop.`
- **Target Condition:** 키보드 입력으로 화면에 나타낼 수 있는 문자·글
- **Precondition:** 키보드 장치와 입력할 내용이 있다.

## 언제 이 말을 꺼낼까?

컴퓨터실에서 노트북을 열고 글쇠를 눌러 메시지를 화면에 입력한다. **키보드 방식**을 말하고 싶으면 `type`을 쓴다.

- **TARGET:** 키보드로 입력할 수 있는 문자·메시지·문서.
- **BASIC/RESULT + HOW:** 화면에 글이 생김 + **키보드의 글쇠를 눌러 입력하는** 방식.
- **이 말을 고르는 이유:** 펜으로도 `write`할 수 있다. 키보드를 썼다는 사실이 중요하면 `type`이다.
- **한 문장:** `I typed a message on the laptop.`
- **내 장면:** 오늘 키보드로 입력한 짧은 글을 떠올려 보자.

## Scene Scenario
- **PLACE:** 컴퓨터실 노트북 앞
- **SITUATION / PROBLEM:** 선생님께 보낼 글을 수정하기 쉽도록 디지털 문서에 남겨야 한다.
- **PURPOSE:** 메시지를 화면에 입력한다.
- **WHY THIS HOW?:** 손글씨가 아니라 손가락으로 키보드를 눌러 글을 만들므로 `TYPE`을 쓴다.
- **ACTION → RESULT:** Mina가 글쇠를 차례로 눌러 화면에 문장을 남긴다.

```text
WRITE + 키보드 입력 = TYPE
```

## Minimal Contrast

펜으로도 노트북으로도 `write`할 수 있지만, 키보드 방식은 `type`이라고 한다.
