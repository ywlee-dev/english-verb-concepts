# AGREE Family

## 상황에서 꺼내기 — 설명을 보기 전에

가상의 학급 소풍 장면이다. **제안에 어떤 관계를 맺는지** 보자. 찬성 입장을 밝히는지, 실행 계획으로 채택하는지, 공개 지지하는지, 마음에 들지 않아도 따르는지가 다르다.

1. 선생님의 금요일 소풍 제안에 학생들이 찬성한다고 말했다. → ?
2. 여러 후보를 검토한 뒤 학급이 공원 소풍안을 실제 실행 계획으로 받아들였다. → ?
3. 학생 대표가 학부모 회의에서 공원 소풍안을 공개적으로 지지한다고 밝혔다. → ?
4. 몇몇 학생은 다른 장소를 원했지만 다수의 결정을 막지 않고 공원 소풍안에 따랐다. → ?

<details><summary>동사와 선택 이유 보기</summary>

1. **AGREE** — `The class agreed to the picnic plan.` 제안에 찬성하는 입장이다.
2. **ACCEPT** — `The class accepted the picnic plan.` 제안을 실행할 것으로 받아들였다. 모든 수용이 마음속 찬성을 뜻하지는 않는다.
3. **ENDORSE** — `The class endorsed the picnic plan.` 다른 사람 앞에서 지지 의사를 밝혔다. 최종 승인권이 있다는 뜻은 아니다.
4. **GO ALONG WITH** — `The students went along with the plan.` 적극적이지 않아도 반대하지 않고 따른다.

</details>

**내 장면으로 바꿔 보기:** 최근 다른 사람의 제안을 들었다면, 마음으로 찬성했는지, 실제 채택했는지, 공개 지지했는지, 불만은 있지만 따랐는지 구분해 보자.

## Shared Result

agent가 다른 사람의 제안이나 의견에 **찬성하는 입장**이 된다. `THINK`는 검토 중일 수 있고 `DECIDE`는 선택을 확정하지만, `AGREE`는 제안한 상대와 입장이 맞아지는 사회적 관계다. 여기서는 학급의 소풍 계획이라는 동일 TARGET을 쓴다.

| Verb | Same-target example | Distinctive HOW / commitment |
|---|---|---|
| AGREE | The class agreed to the picnic plan. | 제안에 동의 |
| ACCEPT | The class accepted the picnic plan. | 제안을 받아 실행 대상으로 삼음 |
| ENDORSE | The class endorsed the picnic plan. | 공개적으로 지지함 |
| GO ALONG WITH | The class went along with the picnic plan. | 적극적이지 않아도 반대하지 않고 따름 |

`accept`는 실제 채택, `endorse`는 공개 지지, `go along with`는 소극적인 동의까지 표현한다. 모든 `accept`가 마음속 찬성을 뜻하지는 않으므로 이 장면에서는 학급이 자발적으로 계획을 받아들였다고 한정한다.

## Sound & Forms reference

`agree`, `accept`, `endorse`는 규칙 변화다. `go along with`는 `went along with/gone along with`로 `go`만 바뀐다. 발음·형태 확인: [Cambridge: agree](https://dictionary.cambridge.org/us/pronunciation/english/agree), [accept](https://dictionary.cambridge.org/us/dictionary/english/accept), [endorse](https://dictionary.cambridge.org/us/pronunciation/english/endorse), [go along with](https://dictionary.cambridge.org/us/dictionary/english/go-along-with).
