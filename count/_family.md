# COUNT Family

## Shared Result

agent가 구분 가능한 TARGET들을 하나씩 대응시켜 **몇 개인지** 알아낸다. `MEASURE`는 길이·무게처럼 연속적인 크기를 단위로 알아내고, `COUNT`는 항목의 개수를 알아낸다.

| Verb | Same-target example | Distinctive HOW |
|---|---|---|
| COUNT | count the chairs | 개수를 알아냄 |
| TALLY | tally the chairs | 항목마다 표시를 남기며 셈 |
| RECOUNT | recount the chairs | 같은 것을 다시 세어 확인 |
| COUNT OUT | count out ten chairs | 필요한 개수만큼 하나씩 골라 냄 |
| ENUMERATE | enumerate the chairs | 항목을 빠짐없이 하나씩 열거 |

## Boundary

`COUNT OUT`은 단순 수량 인식에서 더 나아가 그 수만큼 물건을 골라 낸다. `ENUMERATE`는 총수보다 항목을 빠짐없이 열거하는 과정에 무게가 있다. 둘은 넓은 세기 사건의 HOW로 묶되 차이를 개별 노트에 명시한다.

## 상황에서 꺼내기 — 설명을 보기 전에

교실 행사에 의자가 필요하다. 지금 무엇을 알아내거나 해야 할까?

1. 손님 수와 비교하려고 의자가 모두 몇 개인지 알아본다.
2. 의자가 하나씩 들어올 때마다 종이에 획을 그어 수를 누적한다.
3. 쉬는 시간 뒤 의자가 옮겨졌을지 몰라 다시 센다.
4. 창고에서 손님용 의자 열 개를 하나씩 세어 따로 빼놓는다.
5. 고장 난 의자 세 개가 **어느 것인지** 선생님에게 하나씩 열거한다.

<details><summary>동사와 선택 이유 보기</summary>

1. `I counted the chairs.` — 총 개수를 알아본다.
2. `I tallied the chairs as they came in.` — 들어올 때마다 기록하며 센다.
3. `I recounted the chairs.` — 이전 수를 확인하려고 다시 센다.
4. `I counted out ten chairs.` — 정해진 수만큼 분리해 낸다.
5. `I enumerated the chairs that needed repair.` — 숫자만이 아니라 각 항목을 빠짐없이 지목한다. 격식 있는 표현이다.
