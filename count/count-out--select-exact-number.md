# COUNT OUT — select an exact number

## 0. Sound & Forms

- **Pronunciation (US):** /kaʊnt aʊt/ [카운트**아웃**] — 구동사이며 뒤 단어 `out`에 강세가 있다.
- **Forms:** `count out` — `counted out` — `counted out`; 규칙 변화다.
- **시제와 결과:** `Mina counted out ten chairs for the guests in the storage room.` → `Mina has counted out ten chairs. They are set aside by the door now.` 골라낸 동작과 현재의 분리된 상태를 구별한다.

- **Sense:** 필요한 수를 말하거나 확인하면서 물건을 하나씩 골라 내다.
- **Example:** `Mina counted out ten chairs for the guests.`
- **Target Condition:** 전체 중 필요한 개수만큼 분리해 낼 수 있는 개별 물건들
- **Precondition:** 목표 수가 정해져 있고 그만큼의 물건이 있다.

## 언제 이 말을 꺼낼까?

창고에는 의자가 많지만 손님용은 정확히 열 개만 필요하다. 하나씩 세면서 열 개를 출입문 옆으로 빼놓는다. **정해진 수만큼 골라내면** `count out`이다.

- **TARGET:** 전체에서 필요한 개수만큼 분리해 낼 수 있는 의자·동전·카드.
- **BASIC/RESULT + HOW:** 필요한 개수가 따로 확보됨 + **하나씩 세며 그 수만큼 분리하는** 방식. 단순히 전체 수를 아는 것보다 한 단계 더 있다.
- **이 말을 고르는 이유:** 창고 의자 수를 알아내면 `count`; 열 개를 세어 꺼내면 `count out`이다.
- **한 문장:** `I counted out ten chairs for the guests.`
- **내 장면:** 여러 물건에서 필요한 개수만큼 골라낸 일을 떠올려 말해 보자.

## Scene Scenario
- **PLACE:** 행사 전 창고
- **SITUATION / PROBLEM:** 손님용 의자는 정확히 열 개만 교실로 가져가야 한다.
- **PURPOSE:** 전체 재고에서 열 개를 골라 낸다.
- **WHY THIS HOW?:** 총수가 몇 개인지 아는 데서 끝나지 않고 목표 수만큼 분리하므로 `COUNT OUT`을 쓴다.
- **ACTION → RESULT:** Mina가 하나씩 수를 말하며 의자 열 개를 출입문 쪽으로 빼놓는다.

```text
COUNT + 정해진 개수만큼 분리 = COUNT OUT
```

## Minimal Contrast

창고 의자 전체를 `count`하고, 그중 열 개를 `count out`한다.
