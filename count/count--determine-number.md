# COUNT — determine the number

## 0. Sound & Forms

- **Pronunciation (US):** /kaʊnt/ [**카**운트] — 단음절이다.
- **Forms:** `count` — `counted` — `counted`; 규칙 변화다.
- **시제와 결과:** `Mina counted the chairs before the presentation.` → `Mina has counted the chairs. She knows there are fourteen now.` 세는 동작과 현재 알아낸 개수 상태를 구별한다.

- **Sense:** 구분 가능한 대상들을 하나씩 세어 전체 개수를 알아내다.
- **Example:** `Mina counted the chairs.`
- **Target Condition:** 하나씩 구별하여 수를 대응시킬 수 있는 항목들
- **Precondition:** 셀 대상의 범위가 정해져 있고 중복·누락 없이 볼 수 있다.

## 언제 이 말을 꺼낼까?

손님 열두 명이 오는데 의자가 충분한지 모른다. 교실에 놓인 의자를 하나씩 세어 14개라는 수를 알아낸다. **몇 개인지**가 질문이면 `count`다.

- **TARGET:** 하나씩 구분해 수를 붙일 수 있는 의자·사람·표.
- **BASIC/RESULT + HOW:** 개수를 알아냄 + **개별 항목마다 수를 대응시키는** 방식.
- **이 말을 고르는 이유:** 의자의 높이를 알아볼 때는 `measure`한다. 여기서는 분리된 의자가 몇 개인지 센다.
- **한 문장:** `I counted the chairs. There are fourteen.`
- **내 장면:** 지금 내 주변에서 셀 수 있는 것 하나를 골라 영어로 말해 보자.

## Scene Scenario
- **PLACE:** 발표 전 교실
- **SITUATION / PROBLEM:** 손님 열두 명이 올 예정인데 의자가 충분한지 모른다.
- **PURPOSE:** 현재 의자의 개수를 알아낸다.
- **WHY THIS HOW?:** 길이나 무게가 아니라 분리된 의자들이 몇 개인지 알아야 하므로 `COUNT`를 쓴다.
- **ACTION → RESULT:** Mina가 의자를 하나씩 가리키며 수를 붙여 14개임을 안다.

```text
BEFORE: 전체 개수 모름 → HOW: 항목마다 수 하나 대응 → AFTER: 개수 앎
```

## Minimal Contrast

의자 **몇 개**인지는 `count`, 의자 **얼마나 높은지**는 `measure`한다.
