# MEMORIZE — fix in memory

## 0. Sound & Forms

- **Pronunciation (US):** /ˈmem.ə.raɪz/ [**메**모라이즈] — 첫 음절 강세다.
- **Forms:** `memorize` — `memorized` — `memorized`; 규칙 변화다.
- **시제와 결과:** `Mina memorized the fraction rule at her desk before the test.` → `Mina has memorized the rule. She can recall it in the exact order now.` 기억에 고정한 사건과 현재의 정확한 회수 가능 상태를 구별한다.

- **Sense:** 정보를 나중에 정확히 다시 말하거나 사용할 수 있도록 기억에 고정하다.
- **Example:** `Mina memorized the fraction rule.`
- **Target Condition:** 정확한 형태로 저장하고 회수할 수 있는 말·순서·사실
- **Precondition:** agent에게 반복하거나 연결할 정보가 있으며 정확한 회수가 목표다.

## 언제 이 말을 꺼낼까?

Mina는 원리를 이해하지만 시험에서 규칙 순서를 잊을까 걱정한다. 문장을 가리고 다시 말하는 연습으로 순서를 기억에 넣는다. **정확히 다시 꺼낼 수 있도록 저장하면** `memorize`다.

- **TARGET:** 정확한 형태나 순서로 기억할 수 있는 문장·숫자·사실.
- **BASIC/RESULT + HOW:** 정보가 기억에 고정됨 + **나중에 정확히 회수하려는** 방식. 이해와 암기는 같은 일이 아니다.
- **선택 경계:** 원리를 `understand`해도 문구를 못 외울 수 있고, `memorize`해도 원리를 모를 수 있다.
- **한 문장:** `Mina memorized the fraction rule.`
- **내 장면:** 외워야 했던 짧은 순서나 문장을 하나 떠올려 보자.

## Scene Scenario
- **PLACE:** 시험 전 집의 공부 책상
- **SITUATION / PROBLEM:** Mina는 원리를 이해하지만 규칙의 순서를 시험 중 잊을까 걱정한다.
- **PURPOSE:** 도움 없이 정확한 순서로 규칙을 떠올린다.
- **WHY THIS HOW?:** 넓은 이해보다 특정 정보를 안정적으로 저장하고 그대로 회수하는 것이 목적이므로 `MEMORIZE`를 쓴다.
- **ACTION → RESULT:** Mina가 규칙을 가리고 말해 본 뒤 틀린 부분을 반복해 전체 순서를 기억에 고정한다.

```text
LEARN + 정확한 회수를 위해 기억에 고정 = MEMORIZE
```

## Minimal Contrast

규칙을 `understand`하면 이유를 설명할 수 있고, 규칙을 `memorize`하면 정확한 문구나 순서를 다시 말할 수 있다.
