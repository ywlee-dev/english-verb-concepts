# LEARN — gain knowledge or skill

## 0. Sound & Forms

- **Pronunciation (US):** /lɜːrn/ [**런**] — 단음절이다.
- **Forms:** `learn` — `learned` — `learned`; 미국식은 규칙 변화, 영국식은 `learnt`도 쓴다.
- **시제와 결과:** `Mina learned the fraction rule at the math desk.` → `Mina has learned the rule. She can apply it now.` 지식을 얻은 사건과 현재의 적용 가능한 상태를 구별한다.

- **Sense:** 경험이나 가르침을 통해 새로운 지식 또는 능력을 갖게 되다.
- **Example:** `Mina learned the fraction rule.`
- **Target Condition:** 이해하거나 수행할 수 있는 지식·방법·기술
- **Precondition:** agent는 해당 지식이나 능력을 아직 충분히 갖고 있지 않다.

## 언제 이 말을 꺼낼까?

Mina는 분수 덧셈을 자꾸 틀렸다. 조각을 맞춰 보고 설명을 들은 뒤 이제 규칙을 적용할 수 있다. **전에는 없던 지식·능력을 얻게 되면** `learn`이다.

- **TARGET:** 이해하거나 수행할 수 있는 규칙·방법·기술.
- **BASIC/RESULT + HOW:** 새 지식이나 능력을 얻음 + 어떤 수업·경험을 거쳤는지는 **특정하지 않는** 방식.
- **선택 경계:** `study`는 공부한 활동이고 `learn`은 새로 알게 된 결과다.
- **한 문장:** `Mina learned the fraction rule.`
- **내 장면:** 최근 정말 새로 알게 된 규칙 하나를 떠올려 보자.

## BEFORE → HOW → AFTER

```text
BEFORE: Mina는 분수 덧셈 규칙을 모름
HOW:   설명을 듣고 예제를 연결함
AFTER: Mina는 규칙을 알고 사용할 수 있음
```

## Scene Scenario
- **PLACE:** 수학 교실의 분수 조각 책상
- **SITUATION / PROBLEM:** Mina는 크기가 다른 조각의 수만 더해 틀린 답을 낸다.
- **PURPOSE:** 같은 크기의 조각끼리 더하는 규칙을 새로 갖게 한다.
- **WHY THIS HOW?:** 핵심은 특정 활동보다 ‘모름’에서 ‘앎/할 수 있음’으로 바뀌는 결과이므로 `LEARN`이 중심 동사다.
- **ACTION → RESULT:** 조각을 맞추고 교사의 설명을 들은 뒤 Mina는 공통 분모 규칙을 알고 적용한다.

## Minimal Contrast

`study`와 `practice`는 학습 과정이고, 그 결과 지식이나 능력을 얻으면 `learn`이다.
