# LEARN Family

## Shared Result

agent가 경험·설명·연습을 통해 이전에 없던 지식이나 능력을 갖게 된다.

| Verb | Example | Distinctive Learning HOW |
|---|---|---|
| LEARN | learn the rule | 지식이나 능력을 새로 획득 |
| STUDY | study the rule | 자료에 의도적으로 시간과 주의를 씀 |
| PRACTICE | practice the skill | 같은 수행을 반복해 능력을 높임 |
| DISCOVER | discover the rule | 관찰·탐색 중 스스로 새 사실을 찾아냄 |
| MEMORIZE | memorize the rule | 정확히 다시 꺼낼 수 있도록 기억에 고정 |

## Scenario contrast

분수 규칙을 알게 되면 LEARN, 교재와 예제를 집중해서 살피면 STUDY, 문제 풀이를 반복하면 PRACTICE, 조각을 직접 배열하다 규칙을 찾아내면 DISCOVER, 규칙 문장을 정확히 기억에 넣으면 MEMORIZE가 된다.

`STUDY`와 `PRACTICE`는 학습을 위한 활동이며, 그 자체만으로 지식·능력을 실제로 얻었다는 뜻은 아니다. 이 묶음은 학습 과정과 결과를 함께 비교한다.

## 상황에서 꺼내기 — 설명을 보기 전에

분수 규칙을 익히는 수업이다. **지금 하는 활동과 실제 얻은 결과**를 구별하자.

1. 전에는 몰랐던 분수 규칙을 이제 알고 사용할 수 있다.
2. 시험 전 교과서 설명과 예제에 집중해 시간을 쓴다.
3. 규칙은 알지만 자주 실수해 비슷한 문제를 반복해 푼다.
4. 교사가 알려 주기 전, 분수 조각을 놓아 보다가 숨은 관계를 스스로 찾는다.
5. 규칙 문장의 순서를 가리고 말해 보며 정확히 기억에 넣는다.

<details><summary>동사와 선택 이유 보기</summary>

1. `Mina learned the fraction rule.` — 새 지식을 얻은 결과다.
2. `Mina studied the fraction examples.` — 집중해 살피는 활동이다. 배웠는지는 별개다.
3. `Mina practiced adding fractions.` — 반복 수행한다. 반드시 향상됐다는 뜻은 아니다.
4. `Mina discovered a pattern in the fractions.` — 탐색하며 몰랐던 관계를 찾아낸다.
5. `Mina memorized the fraction rule.` — 나중에 다시 말할 수 있게 기억에 넣는다.

</details>
