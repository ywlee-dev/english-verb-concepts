# PRACTICE — improve by repetition

## 0. Sound & Forms

- **Pronunciation (US):** /ˈpræk.tɪs/ [**프랙**티스] — 첫 음절 강세다.
- **Forms:** `practice` — `practiced` — `practiced`; 규칙 변화다.
- **시제와 결과:** `Mina practiced adding fractions at the math corner.` → `Mina has practiced the skill. She solves the problems more accurately now.` 반복 수행한 사건과 현재의 향상된 정확도 상태를 구별한다.

- **Sense:** 기술을 더 잘 수행하기 위해 같은 종류의 행동을 반복하다.
- **Example:** `Mina practiced adding fractions.`
- **Target Condition:** 반복 수행과 피드백으로 정확도·속도를 높일 수 있는 기술
- **Precondition:** agent가 기본 방법을 어느 정도 알고 개선할 기회가 있다.

## 언제 이 말을 꺼낼까?

Mina는 규칙은 이해하지만 문제를 풀 때 순서를 놓친다. 비슷한 문제를 여러 번 풀고 틀린 곳을 확인한다. **같은 기술을 반복해 연습하면** `practice`다.

- **TARGET:** 반복 수행할 수 있는 풀이·발음·악기 연주 같은 기술.
- **BASIC/RESULT + HOW:** 능력 향상을 목표로 활동함 + **수행을 반복하고 조정하는** 방식. 반드시 곧바로 향상됐다는 뜻은 아니다.
- **선택 경계:** 설명을 읽는 `study`와 달리 `practice`는 직접 해 보는 반복이 중심이다.
- **한 문장:** `Mina practiced adding fractions.`
- **내 장면:** 오늘 반복해서 해 본 기술 하나를 넣어 보자.

## Scene Scenario
- **PLACE:** 교실의 수학 학습 코너
- **SITUATION / PROBLEM:** Mina는 규칙을 이해하지만 문제를 풀 때 자주 순서를 놓친다.
- **PURPOSE:** 풀이를 정확하고 자연스럽게 할 수 있게 한다.
- **WHY THIS HOW?:** 설명을 더 읽기보다 같은 기술을 직접 반복 수행해야 약점이 줄어드므로 `PRACTICE`를 쓴다.
- **ACTION → RESULT:** Mina가 난이도가 비슷한 문제를 풀고 틀린 부분을 고쳐 다음 문제에서 더 정확해진다.

```text
LEARN + 수행 반복과 피드백으로 능력 향상 = PRACTICE
```

## Minimal Contrast

규칙을 알기 위해 예제를 `study`하고, 그 규칙을 빠르고 정확히 쓰기 위해 풀이를 `practice`한다.
