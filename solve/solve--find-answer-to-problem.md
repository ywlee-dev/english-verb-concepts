# SOLVE — find the answer to a problem

## 0. Sound & Forms

- **Pronunciation (US):** /sɑːlv/ [살브] — 한 음절; 끝의 /v/를 확인한다.
- **Forms:** `solve` (기본형/현재) — `solved` (과거) — `solved` (과거분사)
- **시제와 결과:** `Mina solved the math problem yesterday.` → `Mina has solved the math problem. She knows the answer now.` `solved`는 여기서 현재완료의 동사형이다.

- **Sense:** 수학 문제에 맞는 답을 찾아 풀다.
- **Example:** `Mina solved the math problem before class ended.`
- **Result Verb:** `SOLVE` 자체가 공통 결과다.
- **Targets:** math problem, puzzle, equation
- **Target Condition:** 맞는 답이나 해결 절차를 찾을 수 있는 과제
- **Compatibility:** `solve the math problem` / `work out the math problem` 모두 자연스럽고 후자는 계산 단계를 강조한다.
- **Precondition:** 문제가 제시되어 있고 아직 답을 모른다.

## 언제 이 말을 꺼낼까?

수업이 끝나기 전 칠판 문제의 답을 찾아 제출해야 한다. 식을 세우고 답을 확인했다. **어떤 방식보다 해답을 찾은 결과**를 말할 때 `solve`다.

- **TARGET:** 맞는 답이나 해결 절차를 찾을 수 있는 문제·퍼즐·방정식.
- **BASIC/RESULT + HOW:** 문제의 답을 찾음 + 풀이 방법은 **열어 둔** 방식.
- **선택 경계:** `think about the problem`은 답을 못 찾았을 수 있다. `solve`는 해답에 도달한 장면이다.
- **한 문장:** `I solved the math problem before class ended.`
- **내 장면:** 오늘 실제로 답을 찾은 작은 문제를 말해 보자.

```text
BEFORE: 문제와 미지수가 있지만 답이 없음
HOW: 조건을 읽고 계산·검산
AFTER: 조건에 맞는 답을 알고 설명할 수 있음
```

## Scene Scenario

- **PLACE:** 수업이 끝나기 직전의 교실
- **SITUATION:** 칠판의 마지막 문제에 아직 답을 쓰지 못했다.
- **PURPOSE:** 정답과 풀이를 완성한다.
- **WHY THIS HOW?:** 생각만 하는 것이 아니라 검증 가능한 답에 도달해야 한다.
- **ACTION → RESULT:** 미나가 식을 세우고 값을 대입해 확인한다. 답을 적어 제출한다.

`solve(target=math problem, time=before class ended)`에서 `before`는 완료 시점의 한계다. `think about`은 답을 찾았다는 뜻이 아니다.
