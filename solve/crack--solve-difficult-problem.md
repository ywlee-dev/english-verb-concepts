# CRACK — solve a difficult problem

## 0. Sound & Forms

- **Pronunciation (US):** /kræk/ [크랙] — 한 음절; 과거형 `cracked`의 끝소리는 /t/.
- **Forms:** `crack` (기본형/현재) — `cracked` (과거) — `cracked` (과거분사)
- **시제와 결과:** `Mina cracked the math problem yesterday.` → `Mina has cracked the math problem. She can explain the answer now.` `cracked`는 여기서 현재완료의 동사형이다.

- **Sense:** 어렵고 막혀 있던 문제를 마침내 풀다. 여기서는 깨뜨린다는 물리적 의미가 아니다.
- **Example:** `Mina finally cracked the math problem.`
- **Result Verb:** `SOLVE`; 정답에 도달한다.
- **Targets:** math problem, puzzle, code
- **Target Condition:** 풀기 어렵지만 핵심 단서를 잡으면 해결 가능한 과제
- **Compatibility:** `solve the math problem` / `crack the math problem` 모두 가능하며 후자는 난관을 돌파한 느낌이 있다.
- **Precondition:** 여러 번 시도했지만 아직 답을 못 찾았다.

## 언제 이 말을 꺼낼까?

친구들도 못 푼 어려운 문제를 오래 붙잡았다. 빠뜨린 조건 한 줄을 발견하자 답이 나온다. **막힌 난관을 마침내 돌파했다**면 `crack`이 어울린다.

- **TARGET:** 어려웠지만 핵심 단서를 잡으면 풀 수 있는 문제·암호·퍼즐.
- **BASIC/RESULT + HOW:** 해답에 도달함 + **어려운 핵심을 뚫어 낸** 느낌의 구어적 방식. 물건을 깨뜨린다는 뜻은 아니다.
- **선택 경계:** 쉬운 문제에 `crack`을 쓰면 과장될 수 있다. 중립적인 말은 `solve`다.
- **한 문장:** `I finally cracked the math problem.`
- **내 장면:** 여러 번 막혔다가 해결한 문제를 떠올려 보자.

```text
BEFORE: 어려운 문제 앞에서 여러 풀이가 실패
HOW: 놓쳤던 조건을 발견하고 풀이를 다시 구성
AFTER: 답을 찾고 왜 맞는지 설명 가능
```

## Scene Scenario

- **PLACE:** 방과 후 조용한 교실
- **SITUATION:** 친구들도 풀지 못한 문제를 미나가 오래 붙잡고 있다.
- **PURPOSE:** 막힌 지점을 뚫고 답을 찾는다.
- **WHY THIS HOW?:** 보통 풀이보다 어려운 난관을 넘은 성취가 강조된다.
- **ACTION → RESULT:** 미나가 조건 한 줄을 다시 읽고 빠뜨린 관계를 발견한다. 새 식으로 답을 구한다.

`crack(target=math problem)`; `finally`는 오랜 시도 끝의 완료를 부각한다. 쉬운 문제에 쓰면 과장될 수 있다.
