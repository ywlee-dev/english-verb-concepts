WRITE 묶음 — 같은 메시지, 다른 글쓰기

미나가 메시지를 글로 남긴다. 나중에 다시 볼 수 있는 글이 생긴다는 결과는 같고, 그냥 쓰는지, 잊기 전에 급히 몇 글자만 적는지, 고칠 첫 버전인지, 키보드로 치는지, 표현과 순서를 고민해 짓는지만 바꾸면 write · jot down · draft · type · compose로 갈린다. 17 SAY가 지금 소리로 전한다면, WRITE는 나중에 읽을 글로 남긴다.

"쓰다" 하나로 다 될 것 같다. 그런데 몇 글자만 급히, 아직 최종본이 아닌, 펜이 아니라 키보드로, 표현과 순서를 골라 지은을 말하고 싶을 때는? 그리고 글로 남기지 않고 지금 소리로 전하면? 하나씩 빼 보세요.

장소

1. 무엇인가 — "글로 남김"에 HOW가 붙는다

이 묶음의 BASIC/RESULT는 agent가 언어적 내용을 문자로 만들어 종이·화면 등에 남김 = WRITE다. 여기에 빠른 메모 · 수정 예정 · 키보드 · 의도적 구성이 붙는다. 노트의 식을 그대로 옮겼다.

WRITE+언어를 문자로 표현 (방식 미지정)=WRITE WRITE+빠르고 짧은 메모=JOT DOWN WRITE+수정 예정인 첫 버전=DRAFT WRITE+키보드 입력=TYPE WRITE+내용·표현·구조를 의도적으로 설계=COMPOSE

노트가 짚은 점: write는 펜인지 키보드인지 열려 있다. 형태는 write — wrote — written(불규칙, 소리는 right와 같음), jot — jotted(t를 겹쳐 적음).

2. 그림에서 일어나는 일

  • 글로 남김 → 진이 먼저 집에 가서 말로 전할 수 없다. 미나가 새 과제 내용을 종이에 적어 진의 책상에 둔다. Mina wrote a message to Jin.
  • 급히 적음 → 종 치기 직전 선생님이 과제 페이지를 바꿨다. 공책 귀퉁이에 p. 42만 빨리. Mina jotted down the new page number.
  • 초안 → 선생님께 보낼 결석 안내를 바로 보내지 않고 첫 버전을 적어 어색한 곳을 표시한다. Mina drafted a message to the teacher.
  • 입력 → 컴퓨터실 노트북에서 글쇠를 눌러 화면에 문장을 남긴다. Mina typed a message on the laptop.
  • 지음 → 생일 카드에 평범한 한 줄 대신 추억 → 축하 → 바람 순서를 정해 문장을 고른다. Mina composed a birthday message for Jin.
  • 어느 장면이든 글을 남겼으니 write도 맞다. 그래서 WRITE 칩이 같이 켜진다.

3. write의 짝 — to · back · down

write 혼자보다 짝 낱말과 함께 더 자주 나온다. 누구에게 보내는 글인지, 답장인지, 잊지 않게 받아 적는지가 짝으로 갈린다.

모양그림문장한국어
write + 글글을 남김I wrote a message to Jin.진에게 메시지를 썼다
write to + 사람그 사람에게 보냄I wrote to my grandma.할머니께 편지를 썼다
write back받은 글에 답함Please write back soon.곧 답장해 줘
write down들은 것을 받아 적음Write down your answer.답을 적어라
jot down급히 짧게 적음I jotted down the page number.쪽 번호를 급히 적었다

한국어 "적어 둬"는 대개 write down · jot down이다. down은 펜끝이 종이로 내려가 기록이 남는 그림 — 02 구동사의 방향.

4. 무엇이 다른가 — 질문을 따라 고른다

점선 테두리가 WRITE 묶음이다. 글로 남기지 않고 지금 소리로 전하면 테두리 밖 문으로 SAY 묶음에 간다.

5. 실제 문장으로 — it은 어디에

짝 낱말(down · up)이 붙는 구동사는 it · them이 가운데에 들어간다. 짝이 없는 draft · compose는 it이 바로 뒤에 온다.

6. 몸으로 해 보기

  • WRITE — 허공에 펜을 쥐고 한 줄을 길게 써 내려간다.
  • JOT DOWN — 손바닥에 숫자 두 개만 휘갈긴다.
  • DRAFT — 한 줄 쓰고, 쭉 긋고, 위에 다시 쓴다.
  • TYPE — 책상 위에서 열 손가락을 톡톡톡.
  • COMPOSE — 턱을 괴고 "첫째, 둘째, 셋째" 하며 손가락으로 순서를 센다.
확인할 것
  • 0+절의 장소별 대화는 노트에 없는 작문이다. 자연스러운지 사전 예문으로 확인할 것. 음악실 장면의 composed this song은 노트의 TARGET(메시지·편지·글) 밖이다.
  • 3절 표에서 노트에 있는 것은 write a message · jot down까지다. write to · write back · write down은 노트에 없다.
  • 5절의 it 자리(wrote it down · jotted it down · typed it up)와 ✗ 판정(jotted down a long essay · typed it with a pen), "다른 모양"(wrote Jin a message · my first draft · composed a song)은 노트에 없다. jot down의 ✗은 노트의 "긴 설명문을 쓴다면 write다"를 문장으로 만든 것이다. "경향 한 줄"은 그림을 위한 정리다.
  • 0절 "대신 말하면"의 △·✗ 판정은 짐작이다.
  • 묶음 표는 jot down의 같은 TARGET 예로 jot down a message를 드는데, jot down 노트의 TARGET은 "번호·이름·생각" 같은 짧은 정보다. 맨 위 그림은 노트를 따라 페이지 번호로 했다. 묶음 표 예를 바꿀지 정할 것.
  • compose 노트의 Minimal Contrast "말을 그대로 받아 적으면 write"는 write 노트의 "말이나 생각을 문자로 표현"과 잘 맞지만, "받아 적다"는 보통 write down이다. 예문을 하나 붙이면 좋겠다.
