# PUT — cause to be in a place

## 0. Sound & Forms

- **Pronunciation (US):** /pʊt/ [풋] — 한 음절; 긴 /uː/가 아닌 /ʊ/다.
- **Forms:** `put` — `put` — `put`; 세 형태의 철자가 같다.
- **시제와 결과:** `She put the book on the living-room table after coming home.` → `She has put the book on the table. It is there now.` 어떤 방식으로 내려놓았는지는 특정하지 않는다.

- **Sense:** TARGET을 특정 장소나 위치에 있게 만들다.
- **Example:** `She put the book on the table.`
- **Target Condition:** agent가 위치를 바꾸어 목적 장소에 둘 수 있는 대상
- **Preconditions:** TARGET과 목적 장소가 있으며 agent가 TARGET을 통제한다.

## 언제 이 말을 꺼낼까?

집에 돌아와 손에 든 책을 거실 탁자 위에 둔다. TARGET은 책·컵·열쇠처럼 다른 위치에 놓을 수 있는 것이다. `PUT = 대상이 특정 위치에 있게 되는 기본 결과 + 배치 방식은 열어 두는 HOW`. 조심스럽게 놓았는지 떨어뜨렸는지는 따로 표현한다. `I put the book on the table.` 오늘 어디에 무엇을 두었는지 말해 보자.

```text
BEFORE: book이 손에 있음
HOW: 배치 방식 미지정
AFTER: book이 table 위에 있음
```

## Scene Scenario
- **PLACE:** 집 거실의 탁자 옆
- **SITUATION:** 외출에서 돌아와 손에 든 book을 내려두려 한다.
- **PURPOSE:** book이 탁자 위에 있게 만든다.
- **WHY THIS HOW?:** 정밀함·방향·충격보다 최종 위치만 중요해 `PUT`이 선택된다.
- **ACTION → RESULT:** book을 손에서 탁자 위로 옮겨 지지되게 둔다.

```text
PLACE에 있게 함 + 방식 미지정 = PUT
```
