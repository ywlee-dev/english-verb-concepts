# SET — put in position

## 0. Sound & Forms

- **Pronunciation (US):** /set/ [셋] — 한 음절이다.
- **Forms:** `set` — `set` — `set`; 세 형태의 철자가 같다.
- **시제와 결과:** `She set the book on the reading stand before the talk.` → `She has set the book on the stand. The page is ready to read now.` 사용할 준비가 된 자세로 두는 HOW다.

- **Sense:** TARGET을 안정적이거나 바로 사용할 수 있는 위치·자세로 두다.
- **Example:** `She set the book on the reading stand.`
- **Target Condition:** 특정 자세나 준비 상태로 배치될 수 있는 대상

## 언제 이 말을 꺼낼까?

발표 전에 펼친 책을 독서대 홈에 맞춰 둔다. TARGET은 책·컵·기기처럼 어떤 자리에 놓거나 자세를 맞출 수 있는 것이다. `SET = 위치를 정하는 기본 결과 + 안정되거나 쓰기 좋은 자세로 두는 HOW`(이 장면의 뜻). `set`에는 다른 뜻도 많으므로 여기서는 배치 의미만 익힌다. `She set the book on the stand.` 준비해 둔 물건을 넣어 말해 보자.

## Scene Scenario
- **PLACE:** 발표대의 독서대 앞
- **SITUATION:** 발표자가 곧 book의 특정 페이지를 읽어야 한다.
- **PURPOSE:** 손을 떼어도 펼쳐진 페이지가 보이는 준비 상태를 만든다.
- **WHY THIS HOW?:** 단순한 위치보다 안정되고 사용할 준비가 된 자세가 중요해 `SET`이 선택된다.
- **ACTION → RESULT:** book을 독서대 홈에 맞추고 페이지를 펼쳐 고정한다.

```text
PUT + 안정적·사용 준비된 자세 = SET
```
