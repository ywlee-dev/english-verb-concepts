# PUT Family

## Shared Result

## 상황에서 꺼내기 — 설명을 보기 전에

책을 탁자나 독서대에 두는 방식을 상상해 보자.

1. 탁자 위에 두었다는 사실만 말한다.
2. 오래된 책을 표시선 안에 조심스럽게 둔다.
3. 읽기 쉽게 독서대에 맞춰 둔다.
4. 젖은 책을 평평하게 눕혀 둔다.
5. 손에서 놓아 탁자 위로 짧게 떨어뜨린다.

<details><summary>동사와 선택 이유 보기</summary>

1. `put`: I put the book on the table. 위치 결과가 핵심이다.
2. `place`: I placed the book on the display table. 주의 깊게 위치를 정한다.
3. `set`: I set the book on the stand. 사용할 자세로 둔다.
4. `lay`: I laid the book flat on the table. 평평하게 눕힌다.
5. `drop`: I dropped the book onto the table. 지지를 놓아 떨어뜨린다.

</details>

내 장면으로 바꿔 보기: 오늘 어디엔가 둔 물건 하나를 떠올려 장소만 중요한지, 놓는 방식이 중요한지 말해 보자. `drop`은 의도치 않게 떨어뜨릴 때도 쓴다.

agent가 TARGET을 특정 PLACE나 POSITION에 있게 만든다.

| Verb | Same-target example | Distinctive HOW / Result |
|---|---|---|
| PUT | put the book on the table | 배치 방식 미지정 |
| PLACE | place the book on the table | 선택한 위치에 조심스럽고 정확하게 배치 |
| SET | set the book on the stand | 안정적이거나 사용할 준비가 된 자세로 배치 |
| LAY | lay the book on the table | 넓은 면이 표면에 닿도록 평평하게 배치 |
| DROP | drop the book on the table | 손의 지지를 놓아 아래로 떨어뜨려 배치 |

```text
PUT + 조심스럽고 정확하게 = PLACE
PUT + 안정적·준비된 자세   = SET
PUT + 평평하게 눕혀서      = LAY
PUT + 지지를 놓아 떨어뜨림 = DROP
```

## Scenario contrast

책을 탁자 위에 둔다는 결과만 말하면 PUT, 전시 위치에 정확히 두면 PLACE, 독서대에 바로 읽을 자세로 두면 SET, 표지가 위를 향하게 평평히 놓으면 LAY, 급히 손을 놓아 탁자 위로 떨어뜨리면 DROP이 된다. 정확성·방향·준비 상태·중력이 HOW를 결정한다.

## Sound & Forms reference

`put → put → put`, `set → set → set`은 세 형태가 같다. `lay → laid → laid`는 `lie → lay → lain`과 구별한다. `place`는 규칙 변화이고 `drop → dropped → dropped`는 `p`를 겹친다. 발음·형태 확인: [Cambridge: put](https://dictionary.cambridge.org/us/dictionary/english/put), [place](https://dictionary.cambridge.org/us/pronunciation/english/place), [set](https://dictionary.cambridge.org/us/dictionary/english/set), [lay](https://dictionary.cambridge.org/us/dictionary/english/lay), [drop](https://dictionary.cambridge.org/us/pronunciation/english/drop).
