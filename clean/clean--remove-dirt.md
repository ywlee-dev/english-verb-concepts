# CLEAN — remove dirt

## 0. Sound & Forms

- **Pronunciation (US):** /kliːn/ [클**린**] — 단음절이다.
- **Forms:** `clean` — `cleaned` — `cleaned`; 규칙 변화다.
- **시제와 결과:** `Mina cleaned the classroom floor after art class.` → `Mina has cleaned the floor. The next class can use it now.` 오염을 없앤 동작과 현재의 사용 가능한 상태를 구별한다.

- **Sense:** TARGET의 오염이나 불필요한 물질을 없애 깨끗하게 하다.
- **Example:** `Mina cleaned the classroom floor.`
- **Target Condition:** 오염이 붙거나 쌓일 수 있고 제거 뒤 상태가 달라지는 표면·공간
- **Precondition:** TARGET에 먼지·얼룩 등이 있고 제거할 수단이 있다.

## 언제 이 말을 꺼낼까?

미술 수업 뒤 교실 바닥에 흙과 물감 자국이 남았다. 도구보다 **바닥을 다시 깨끗하게 만들었다**는 결과가 중요하면 `clean`이다.

- **TARGET:** 오염이 쌓였다가 제거될 수 있는 바닥·책상·방.
- **BASIC/RESULT + HOW:** 오염이 줄어 깨끗해짐 + 제거 방식을 **열어 둔 채** 결과를 말한다. 특정 도구가 정해진 것은 아니다.
- **이 말을 고르는 이유:** 물을 썼는지 솔을 썼는지 알 필요가 없다면 `clean`만으로 충분하다.
- **한 문장:** `I cleaned the classroom floor.`
- **내 장면:** 내가 깨끗하게 만든 공간 하나를 떠올려 말해 보자.

## Scene Scenario
- **PLACE:** 미술 수업 뒤 교실
- **SITUATION / PROBLEM:** 바닥에 흙과 물감 자국이 남아 다음 반이 쓰기 어렵다.
- **PURPOSE:** 바닥을 다시 사용할 수 있는 상태로 만든다.
- **WHY THIS HOW?:** 어떤 도구를 쓰는지보다 오염이 사라지는 결과가 핵심이라 `CLEAN`을 쓴다.
- **ACTION → RESULT:** Mina가 먼지와 자국을 제거해 바닥이 깨끗해진다.

```text
BEFORE: 오염 있음 → HOW: 불필요한 물질 제거 → AFTER: 깨끗한 상태
```

## Minimal Contrast

바닥을 `clean`하는 방법으로 물로 `wash`하거나 빗자루로 `sweep`할 수 있다.
