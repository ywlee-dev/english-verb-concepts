# QUESTION — ask closely for clarification or evidence

## 0. Sound & Forms

- **Pronunciation (US):** /ˈkwes.tʃən/ [**퀘스**천] — 첫 음절 강세다.
- **Forms:** `question` — `questioned` — `questioned`; 규칙 변화다.
- **시제와 결과:** `The manager questioned the employees about the incident yesterday.` → `The manager has questioned the employees. She can now compare their accounts with the report.` 설명과 근거를 집중적으로 확인한 질문이다.

## Sense

- 이번 의미: 사실·설명·근거를 확인하기 위해 TARGET에게 집중적으로 질문하다.
- 대표 문장: `The manager questioned the employees about the incident.`
- Result Family: `ASK`

## Target Condition

> 확인하려는 사건이나 주장에 관해 정보·설명·근거를 제공할 수 있다고 여겨지는 대상

## 언제 이 말을 꺼낼까?

장비 사고 기록과 초기 설명이 맞지 않는다. 관리자가 관련자에게 시간·행동·근거를 구체적으로 묻는다. **설명의 신뢰성을 집중 확인하면** `question`이다.

- **TARGET:** 사건이나 주장에 관해 설명·근거를 제공할 수 있는 사람.
- **BASIC/RESULT + HOW:** 질문을 통한 정보 요청 + **사실과 설명을 집중적으로 검토하는** 방식. 답을 들어도 진실을 알아냈다는 뜻은 아니다.
- **선택 경계:** 중립적 정보 요청은 `ask`; 모순을 따져 묻는 분위기는 `question`에 가깝다.
- **한 문장:** `The manager questioned the employees about the incident.`
- **내 장면:** 설명이 맞는지 확인하려고 다시 묻는 상황을 떠올려 보자.

## Result + HOW

```text
ASK
+ 특정 사실이나 설명을 검토하려고 집중적으로 캐묻거나 확인
= QUESTION
```

## Scene

```text
BEFORE: 관리자가 사건 경위에 의문이 있음
   ↓ 관련자에게 구체적인 질문을 이어 가며 설명과 근거를 확인
AFTER:  사건에 관한 설명을 얻거나 기존 설명의 신뢰성을 평가함
```

## Minimal Contrast

- `ask the employees`: 중립적으로 질문함
- `question the employees`: 설명을 검토하거나 의심하며 집중적으로 확인하는 뉘앙스가 추가됨

## Scene Scenario
- **PLACE:** 사고 조사 회의실
- **SITUATION:** 장비 사고 기록과 직원들의 초기 설명이 서로 맞지 않는다.
- **PURPOSE:** 사실관계와 설명의 신뢰성을 확인한다.
- **WHY THIS HOW?:** 중립적인 정보 요청보다 모순을 검토하는 집중적 질문이 필요해 `QUESTION`이 선택된다.
- **ACTION → RESULT:** 시간·행동·증거를 구체적으로 되물어 설명을 비교하고 불일치를 확인한다.
