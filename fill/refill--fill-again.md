# REFILL — fill again

## 0. Sound & Forms

- **Pronunciation (US):** /ˌriːˈfɪl/ [리**필**] — 뒤 음절 강세다.
- **Forms:** `refill` — `refilled` — `refilled`; 규칙 변화다.
- **시제와 결과:** `Mina refilled the box with new donated books.` → `Mina has refilled the box. It is ready for the next shipment now.` 다시 채운 동작과 현재의 재사용 준비 상태를 구별한다.

- **Sense:** 쓰거나 비워서 내용물이 줄어든 용기·공간을 다시 채우다.
- **Example:** `Mina refilled the box with books.`
- **Target Condition:** 이전에 채워진 적이 있고 다시 넣을 수 있는 용기·공간
- **Precondition:** 내용물이 사용·이동되어 용량이 다시 비었다.

## 언제 이 말을 꺼낼까?

걷는 동안 물병의 물을 거의 다 마셨다. 급수대에서 같은 물병에 물을 다시 담는다. **TARGET**은 물병, 원하는 **RESULT**는 줄어든 물이 다시 채워진 상태다. 처음 사용하는 빈 병을 채우는 장면이 아니다.

- **내가 할 말:** `I refilled my water bottle.`
- **BASIC/RESULT + HOW:** 빈 용량이 채워짐 + 쓰면서 줄어든 것을 다시 채움 = `REFILL`
- **선택 기준:** 처음 채우는 사실이면 `fill`; 한 번 사용해 줄어든 내용물을 다시 채우면 `refill`이다.
- **한 번 더 떠올리기:** 비어 가는 잉크 카트리지에 잉크를 다시 넣었다면? → `I refilled the ink cartridge.`

## Scene Scenario
- **PLACE:** 첫 배송을 마친 학교 포장실
- **SITUATION / PROBLEM:** 책을 꺼낸 상자가 비었고 기증 책이 새로 들어왔다.
- **PURPOSE:** 같은 상자를 다시 사용해 다음 배송을 준비한다.
- **WHY THIS HOW?:** 처음 채우는 것이 아니라 비워진 용기를 두 번째로 채우므로 `REFILL`을 쓴다.
- **ACTION → RESULT:** Mina가 새 책을 상자에 넣어 빈 상자가 다시 찬다.

```text
FILL + 이전에 비운 용기를 다시 채움 = REFILL
```

## Minimal Contrast

새 상자를 처음 `fill`하고, 비운 상자를 다시 `refill`한다.
