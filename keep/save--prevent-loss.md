# SAVE — prevent loss

## 0. Sound & Forms

- **Pronunciation (US):** /seɪv/ [**세**이브] — 단음절이다.
- **Forms:** `save` — `saved` — `saved`; 규칙 변화다.
- **시제와 결과:** `Mina saved the file before closing the program in the computer lab.` → `Mina has saved the file. It stays on the disk after the program closes now.` 손실을 막은 사건과 현재의 안전하게 남은 상태를 구별한다.

- **Sense:** TARGET이 사라지거나 손실되지 않도록 기록·보호하여 나중에 사용할 수 있게 하다.
- **Example:** `Save the file before closing the program.`
- **Target Condition:** 기록하지 않으면 사라질 수 있고 지속 가능한 형태로 보존할 수 있는 정보·작업

## 언제 이 말을 꺼낼까?

문서를 편집하다 프로그램을 닫기 전에 저장 버튼을 누른다. TARGET은 파일·작업 내용처럼 기록하지 않으면 잃을 수 있는 것이다. `SAVE = 잃지 않고 남기는 기본 결과 + 지속되는 형태로 기록하는 HOW`(파일 의미). `keep`은 계속 보유하는 넓은 관계이고 `save`는 여기서 손실 위험을 막는 행동이다. `Save the file before you close the program.` 최근 저장한 작업을 넣어 말해 보자.

## Scene Scenario
- **PLACE:** 컴퓨터실의 문서 편집 프로그램
- **SITUATION / PROBLEM:** 학생이 작성한 file이 메모리에만 있어 프로그램을 닫으면 사라질 수 있다.
- **PURPOSE:** 작업 손실을 막고 다시 열 수 있게 한다.
- **WHY THIS HOW?:** 단순히 갖고 있는 것이 아니라 손실 위험에서 기록으로 보호하므로 `SAVE`가 선택된다.
- **ACTION → RESULT:** 저장 명령을 눌러 file을 디스크에 기록하고 재접속 후에도 남게 한다.

```text
KEEP + 손실 위험 방지 + 지속 가능한 기록 = SAVE
```
