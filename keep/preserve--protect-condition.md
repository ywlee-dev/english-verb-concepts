# PRESERVE — protect condition

## 0. Sound & Forms

- **Pronunciation (US):** /prɪˈzɜːrv/ [프리**저**브] — 뒤 음절 강세다.
- **Forms:** `preserve` — `preserved` — `preserved`; 규칙 변화다.
- **시제와 결과:** `The archive preserved the file in its original format in the preservation room.` → `The archive has preserved the file. Its original format remains unchanged now.` 훼손을 막은 사건과 현재의 원형 유지 상태를 구별한다.

- **Sense:** TARGET의 내용·품질·형태가 시간과 환경 때문에 변하거나 손상되지 않게 유지하다.
- **Example:** `The archive preserved the file in its original format.`
- **Target Condition:** 시간이 지나며 열화·변형될 수 있지만 보호 조치로 원래 상태를 유지할 수 있는 대상

## 언제 이 말을 꺼낼까?

오래된 기록의 내용이 변하지 않도록 원본을 읽기 전용으로 관리한다. TARGET은 파일·사진·음식·건물처럼 시간이나 환경 때문에 성질이 달라질 수 있는 것이다. `PRESERVE = 상태를 유지하는 기본 관계 + 변형이나 훼손을 막는 HOW`. 단순히 보관 장소에 넣는 `store`보다 원형 유지가 핵심이다. `The archive preserved the original file.` 오래도록 지키고 싶은 것을 넣어 보자.

## Scene Scenario
- **PLACE:** 역사 기록 디지털 보존실
- **SITUATION / PROBLEM:** 오래된 file 형식이 손상되거나 새 프로그램에서 변환될 위험이 있다.
- **PURPOSE:** 원본 내용과 형식을 장기간 그대로 유지한다.
- **WHY THIS HOW?:** 단순 저장보다 시간에 따른 훼손·변경을 막는 품질 유지가 핵심이라 `PRESERVE`가 선택된다.
- **ACTION → RESULT:** 읽기 전용 원본과 검증 사본을 여러 저장소에 두어 원형을 유지한다.

```text
KEEP + 장기간 원래 상태 보호 = PRESERVE
```
