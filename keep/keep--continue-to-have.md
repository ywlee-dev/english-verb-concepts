# KEEP — continue to have

## 0. Sound & Forms

- **Pronunciation (US):** /kiːp/ [**킵**] — 단음절이다.
- **Forms:** `keep` — `kept` — `kept`; 불규칙 변화다.
- **시제와 결과:** `Mina kept the file in her work folder until Friday.` → `Mina has kept the file in her work folder. It is still there, so she can use it on Friday.` 계속 보유한 사건과 현재의 사용 가능한 상태를 구별한다.

- **Sense:** TARGET을 잃거나 버리지 않고 계속 보유하거나 상태를 유지하다.
- **Example:** `Keep the file until Friday.`
- **Target Condition:** 시간 동안 보유·상태·관계를 유지할 수 있는 대상

## 언제 이 말을 꺼낼까?

금요일에 다시 볼 파일을 작업 폴더에서 지우지 않고 둔다. TARGET은 파일·책·약속처럼 시간 동안 계속 지니거나 유지할 수 있는 것이다. `KEEP = 보유나 상태가 계속되는 기본 관계 + 유지 방식은 열어 두는 HOW`. 특별한 보관 방법이 중요하지 않을 때 쓴다. `Keep the file until Friday.` 오늘 계속 갖고 있어야 할 것을 넣어 말해 보자.

## Scene Scenario
- **PLACE:** 학생의 노트북 작업 폴더
- **SITUATION / PROBLEM:** file은 당장 제출하지 않지만 금요일까지 다시 확인해야 한다.
- **PURPOSE:** 삭제하지 않고 계속 보유한다.
- **WHY THIS HOW?:** 저장 위치나 보존 기술보다 계속 갖고 있는 결과가 중요해 `KEEP`이 선택된다.
- **ACTION → RESULT:** file을 삭제하지 않고 작업 폴더에 남겨 금요일에도 사용할 수 있게 한다.

```text
보유 상태 + 시간 동안 지속 = KEEP
```
