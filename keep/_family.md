## Shared Result

## 상황에서 꺼내기 — 설명을 보기 전에

완성한 파일을 금요일이나 내년에도 쓰고 싶다. 무엇을 어떻게 유지할지 먼저 골라 보자.

1. 금요일까지 파일을 지우지 않고 갖고 있는다.
2. 삭제 대상이 될 수도 있지만 규정에 따라 계속 남긴다.
3. 내년 수업을 위해 보관 폴더에 넣는다.
4. 편집기를 닫기 전에 작업 내용을 기록한다.
5. 오래된 원본의 내용과 형식이 변하지 않게 관리한다.

<details><summary>동사와 선택 이유 보기</summary>

1. `keep`: Keep the file until Friday. 보유 상태를 이어 간다.
2. `retain`: The school retained the file. 제거 가능성에도 남겨 둔다.
3. `store`: She stored the file in the archive. 나중 사용을 위해 정해진 곳에 둔다.
4. `save`: Save the file before closing the program. 작업 손실을 막도록 기록한다.
5. `preserve`: The archive preserved the original file. 원형과 품질을 지킨다.

</details>

내 장면으로 바꿔 보기: 오늘 만든 파일 하나를 떠올려 잠시 보유할지, 저장할지, 오래 보존할지 선택해 한 문장으로 말해 보자.

TARGET을 잃거나 버리지 않고 계속 보유하거나 원하는 상태로 유지한다.

| Verb | Same-target example | Distinctive Purpose |
|---|---|---|
| KEEP | keep the file | 계속 보유, 목적 미지정 |
| RETAIN | retain the file | 삭제·이전 가능성에도 보유 유지 |
| STORE | store the file | 나중 사용을 위해 정해진 장소에 보관 |
| SAVE | save the file | 손실을 막고 다시 사용할 수 있게 기록 |
| PRESERVE | preserve the file | 장기간 내용·상태가 변하지 않게 보호 |

## Scenario contrast

파일을 계속 갖고 있으면 KEEP, 정책상 삭제하지 않고 남기면 RETAIN, 보관소에 넣어 나중에 찾으면 STORE, 작업 손실을 막기 위해 기록하면 SAVE, 장기간 훼손·변경 없이 유지하면 PRESERVE가 된다. 예상되는 손실과 유지 목적이 HOW를 선택한다.
