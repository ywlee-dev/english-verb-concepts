# STORE — keep for later

## 0. Sound & Forms

- **Pronunciation (US):** /stɔːr/ [스**토**어] — 단음절이다.
- **Forms:** `store` — `stored` — `stored`; 규칙 변화다.
- **시제와 결과:** `The teacher stored the file in the archive at the end of the semester.` → `The teacher has stored the file. She can retrieve it next year now.` 지정 장소에 보관한 사건과 현재의 회수 가능한 상태를 구별한다.

- **Sense:** 나중에 찾거나 사용하도록 TARGET을 정해진 장소·시스템에 보관하다.
- **Example:** `The teacher stored the file in the archive.`
- **Target Condition:** 위치를 정해 보관하고 필요할 때 다시 꺼낼 수 있는 대상

## 언제 이 말을 꺼낼까?

이번 학기엔 안 쓰는 자료를 내년에 찾을 수 있도록 보관 폴더에 넣는다. TARGET은 파일·상자·음식처럼 정해진 곳에 두었다가 다시 꺼낼 수 있는 것이다. `STORE = 대상을 유지하는 기본 관계 + 나중 사용을 위해 장소를 정해 보관하는 HOW`. 지금 당장 쓸 물건을 단순히 옆에 두는 `put`과 목적이 다르다. `She stored the file in the archive.` 나중에 쓸 물건을 어디에 보관하는지 말해 보자.

## Scene Scenario
- **PLACE:** 학교의 디지털 자료 보관소
- **SITUATION / PROBLEM:** 이번 학기에는 쓰지 않지만 내년 수업에서 file이 다시 필요하다.
- **PURPOSE:** 일상 작업 공간에서 치우면서도 나중에 찾을 수 있게 한다.
- **WHY THIS HOW?:** 보유뿐 아니라 지정 위치와 미래 회수가 중요해 `STORE`가 선택된다.
- **ACTION → RESULT:** file을 연도별 archive 폴더로 옮기고 검색 정보를 붙인다.

```text
KEEP + 지정 장소 + 미래 사용 = STORE
```
