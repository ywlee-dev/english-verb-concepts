# CRUSH — break by compression

## 0. Sound & Forms

- **Pronunciation (US):** /krʌʃ/ [크러시] — 한 음절; 끝은 /ʃ/다.
- **Forms:** `crush` — `crushed` — `crushed`; 끝 `-ed`는 /t/다.
- **시제와 결과:** `The machine crushed the empty can at the recycling center.` → `The machine has crushed the can. It takes up less space now.` 위에서 눌러 형태를 무너뜨린 결과다.
- Sense: TARGET을 강하게 눌러 찌그러뜨리거나 구조를 망가뜨리다.
- Target Condition: 압축력을 받으면 형태나 내부 구조가 무너질 수 있는 대상

## 언제 이 말을 꺼낼까?

재활용 기계가 빈 캔을 위에서 눌러 납작하게 만든다. TARGET은 캔·종이컵·과일처럼 압력에 형태가 무너질 수 있는 것이다. `CRUSH = 구조나 형태가 망가지는 기본 결과 + 강하게 압박하는 HOW`. 순간적인 충격이 중심인 `smash`와 다르다. `The machine crushed the empty can.` 눌려 찌그러진 것을 하나 떠올려 말해 보자.
```text
BREAK + 양쪽 또는 위에서 강하게 압축 = CRUSH
```
- Scene: `The machine crushed the can.`
- Contrast: `smash`는 충격, `crush`는 지속적 압력이 핵심이다.

## Scene Scenario
- **PLACE:** 재활용 처리장의 압축기 앞
- **SITUATION:** 빈 can의 부피를 줄여 운반 효율을 높여야 한다.
- **PURPOSE:** can을 납작하게 만들어 차지하는 공간을 줄인다.
- **WHY THIS HOW?:** 순간 충격보다 양쪽에서 누르는 지속적 압력이 핵심이므로 `CRUSH`가 선택된다.
- **ACTION → RESULT:** 압축판이 can을 눌러 형태와 내부 공간을 무너뜨린다.
