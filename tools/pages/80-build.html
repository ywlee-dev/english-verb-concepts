BUILD 묶음 — 같은 대피소, 다른 만들기

학교 운동장 · 재난 현장 · 체육관 · 캠프장에서 대피소를 마련한다. 여러 부분이 결합해 버티는 구조가 된다는 그림은 같고, 방식은 말하지 않는지, 도면과 순서를 따르는지, 완성 부품을 맞추는지, 누운 골조를 세우는지, 이미 있는 장비를 제자리에 연결하는지만 바꾸면 build · construct · assemble · erect · install로 갈린다. 단, install은 새로 만드는 것이 아니다(묶음 노트).

{{PRON}} {{TOP|만드는 방식에 따라 대피소 장면과 무엇에서 시작했는지 띠가 바뀌는 그림|왼쪽은 BASIC + HOW = 동사 식이고, 오른쪽 위는 재료 · 완성 부품 · 누운 골조 · 완성 장비 네 칸 중 무엇에서 시작했는지 보여 주는 띠, 아래는 사람과 대피소다. build는 막대 두 개가 기대어 서고 천이 씌워져 그늘이 생김, construct는 오른쪽 도면을 따라 기초 ①, 벽 ②, 지붕 ③ 순서로 올라감, assemble은 번호 1 · 2가 적힌 완성 패널이 양옆에서 다가와 맞물리고 지붕 패널 3이 얹혀 볼트로 고정됨, erect는 바닥에 누워 있던 골조가 화살표를 따라 위로 서서 고정됨, install은 빈 상자에서 꺼낸 난방기가 제자리에 놓이고 배기관과 전원선이 연결되어 불이 켜지는 장면이다.|BUILD · 구조를 만듦|어떻게 만드나}}

설명을 돕기 위한 단순한 그림이다. 막대 수 · 패널 크기는 그림용이다. 장면은 build/_family.md의 비교표 TARGET(a shelter)과 각 노트의 Scene Scenario(운동장 야외 수업 · 재난 대피소 공사 현장 · 체육관 · 바람 부는 캠프장 · 겨울 대피소 안)를 옮겼다. construct · assemble · erect 노트의 식은 BUILD + …라 BUILD 칩이 같이 켜진다. install 장면에서는 BUILD 칩을 켜지 않았다 — install 노트의 식도 BUILD + …이지만, 묶음 노트가 "INSTALL은 새 구조를 짓는 BUILD와 엄격히 같은 결과는 아니다"라고 하고 install 노트도 "새로 만든 것은 아니다"라고 하기 때문이다.

0. 왜 존재하나 — 이 동사가 없으면 못 그리는 그림

"만들다" 하나로 다 될 것 같다. 그런데 한국어도 짓다 · 시공하다 · 조립하다 · 세우다 · 설치하다로 나눠 말한다. 그리고 구조가 아니라 커피 한 잔을 만들었다면? 하나씩 빼 보세요.

{{EXIST}} {{SCENES|BUILD 묶음 동사가}}

1. 무엇인가 — "구조를 만듦"에 HOW가 붙는다

이 묶음의 BASIC/RESULT는 여러 부품 · 재료를 관계에 맞게 결합하여 지속되는 구조나 작동 가능한 전체를 만든다 = BUILD다. 여기에 도면 · 순서, 완성 부품, 세워 올림, 제자리 연결이 붙는다. 노트의 식을 옮겼다.

MAKE+부품을 구조로 결합=BUILD BUILD+도면 · 계획에 따른 체계적 시공=CONSTRUCT BUILD+준비된 부품을 맞춰 결합=ASSEMBLE BUILD+구조를 위로 세워 고정=ERECT BUILD+장비 배치 · 연결로 사용 가능=INSTALL

노트가 짚은 점: make는 결과물을 만드는 넓은 말이고, build는 부분들이 구조로 결합되는 게 보인다. construct는 build보다 체계적 · 구조적 작업의 느낌이 크지만, 안전 기준을 통과했다는 뜻은 아니다. erect는 기존 골조라면 새로 지은 것이 아닐 수 있고, install은 새로 만든 것이 아니며 설치했다고 작동이 보장되지도 않는다. 대피소 자체는 build, 그 안에 장비는 install.

2. 그림에서 일어나는 일

  • 지음 → 운동장에 햇빛을 피할 곳이 없다. 학생들이 막대를 연결하고 천을 씌워 서 있는 대피소를 만든다. 어떤 절차인지는 말하지 않는다. The students built a shelter.
  • 시공함 → 재난 대피소는 치수와 안전 기준을 따라야 한다. 작업자들이 도면 순서대로 기초부터 지붕까지 짓는다. Workers constructed a shelter from a plan.
  • 조립함 → 벽 · 지붕 패널은 공장에서 이미 완성됐다. 현장에서 번호를 맞추고 볼트로 연결한다. The team assembled the shelter panels.
  • 세움 → 골조가 바닥에 누워 있어 천을 걸 수 없다. 들어 올려 수직으로 고정한다. The team erected the shelter frame.
  • 설치함 → 난방기는 상자에서 꺼냈지만 전원과 배기 연결이 없다. 제자리에 고정하고 연결해 쓸 수 있게 한다. 난방기를 새로 만든 것은 아니다. They installed a heater in the shelter.
  • 위 띠는 "무엇에서 시작했나"다. 재료에서 시작하면 build · construct, 완성 부품이면 assemble, 이미 있던 골조 · 장비면 erect · install.

3. 새로 생기나 — 목적어가 결과물인가, 이미 있던 것인가

한국어 "만들다 · 짓다"의 목적어는 새로 생기는 것이다. 이 묶음에서 그 모양이 맞는 건 build · construct뿐이다. erect · install의 목적어는 이미 있던 것이고, 핵심은 그것을 세우거나 제자리에 연결한 결과다.

동사목적어 (노트)새로 생기나한국어
builda shelter예 — 구조가 생김짓다 · 만들다
constructa shelter from a plan예 — 계획대로시공하다
assemblethe shelter panels부품은 있던 것, 전체가 생김조립하다
erectthe shelter frame아닐 수 있음 (노트)세우다
installa heater in the shelter아니오 — 있던 장비 (노트)설치하다
put up (밖)a tent세움 (일상)치다 · 세우다

그래서 "히터를 만들었다"는 built a heater가 아니라, 이미 있는 히터를 자리에 놓고 이었다면 installed a heater다. install은 프로그램에도 쓴다(install 노트 TARGET의 "프로그램"). 텐트를 칠 때 일상 회화는 erect보다 put up이 흔하다.

4. 무엇이 다른가 — 질문을 따라 고른다

점선 테두리가 BUILD 묶음이다. 여러 부분이 구조가 되는 게 아니라 커피 · 음식처럼 무엇이든 만들어 냄이면 테두리 밖 문으로 MAKE에 간다.

{{FLOW|질문을 따라 BUILD 묶음의 동사를 고르는 흐름 그림|맨 위 Q1 여러 부분이 구조가 되나에서 물건 하나를 만들면 묶음 밖 문 make, 예면 Q2 무엇에서 시작하나로 간다. 재료에서 시작하면 Q3 절차를 말하나에서 말 안 하면 build, 도면 · 순서면 construct, 완성 부품이면 assemble, 이미 있는 것이면 Q4 무엇을 하나에서 위로 세우면 erect, 제자리에 연결하면 install로 갈린다.}}
동사① 시작할 때 (노트)② 끝 모습 (노트)③ 새로 생기나

①② 칸은 각 노트의 Scene Scenario · 시제와 결과를, ③ 칸은 erect · install 노트의 "새로 build한 것은 아닐 수 있다 · 새로 만든 것은 아니다"를 옮겼다. 흐름 그림의 질문 순서와 Q3 · Q4 묶음은 그림을 위해 정했다.

5. 실제 문장으로 — 무엇을, 무엇으로 · 어디에

3절의 갈림을 문장으로 확인한다. build · construct는 목적어가 생긴 결과물이고, erect · install은 있던 것 + 어디에가 자연스럽다.

{{SLOTS|목적어와 뒤에 붙는 말에 따라 문장의 낱말 순서가 바뀌는 그림|위 줄은 맞는 문장, 아래 줄은 틀린 문장이다. 낱말마다 상자로 나누고 위에 주어·동사·목적어·결과 같은 역할을 적었다.|동사|뒤에 붙는 것}}
동사노트 예문다른 모양뜻
buildThe students built a shelter.I'm building a website.웹사이트를 만드는 중
constructWorkers constructed a shelter from a plan.construct a sentence문장을 짜다
assembleThe team assembled the shelter panels.The students assembled in the hall.강당에 모였다
erectThe team erected the shelter frame.The statue was erected in 1950.1950년에 세워졌다
installThey installed a heater in the shelter.I installed the app.앱을 깔았다

경향 한 줄: 새 구조가 생기는 build · construct는 결과물을 목적어로 두고, 있던 것을 다루는 erect · install은 목적어 뒤에 어디에(in · on)를 붙이는 일이 많다.

6. 몸으로 해 보기

  • BUILD — 두 손을 막대처럼 기울여 손끝을 맞대어 지붕 모양을 만든다.
  • CONSTRUCT — 한 손으로 도면을 짚고, 다른 손으로 아래부터 한 층씩 ①②③ 쌓는다.
  • ASSEMBLE — 두 손바닥을 양옆에서 다가오게 해 딸깍 맞춘다.
  • ERECT — 책상에 눕힌 팔뚝을 팔꿈치를 축으로 세워 올려 멈춘다.
  • INSTALL — 상자에서 꺼내 자리에 놓고, 플러그를 꽂는 시늉.
확인할 것
  • 0+절의 장소별 대화는 노트에 없는 작문이다. 자연스러운지 사전 예문으로 확인할 것. 특히 They're constructing a new library · This statue was erected in 1950.
  • 3절의 put up 줄, "부품은 있던 것, 전체가 생김" 판정, "일상 회화는 put up이 흔하다"는 노트에 없는 판단이다.
  • 5절의 "다른 모양" 칸(building a website · construct a sentence · assembled in the hall · was erected in 1950 · installed the app), 아래 그림의 줄(out of sticks · from the parts · on the field, ✗ built a heater), 경향 한 줄은 짐작이다. install의 "프로그램"만 노트 TARGET에 있다.
  • 0절 "대신 말하면"의 △·✗ 판정은 짐작이다. 특히 We put up the frame.은 일상에선 erect보다 자연스러울 수 있다.
  • 맨 위 그림에서 install 장면은 BUILD 칩을 껐다(묶음 노트의 "엄격히 같은 결과는 아니다"). 시작 띠의 네 칸 이름은 그림용이다.
  • 노트 문제: construct 노트는 "결과가 반드시 안전 기준을 통과했다는 뜻은 아니다"라면서 시제와 결과는 It meets the safety standard now.다. install 노트는 "설치가 곧 실제 작동을 보장하지는 않는다"면서 시제와 결과는 It is running now.다. 둘 다 "이 장면에선 그렇다"로 읽을 수 있지만 맞춰 둘 것.
  • 노트 문제: install 노트의 식 BUILD + 장비 배치 · 연결 = INSTALL은 같은 노트의 "새로 만든 것은 아니다", 묶음 노트의 "엄격히 같은 결과는 아니다"와 어긋난다. build 노트만 식이 MAKE + …로 시작한다(다른 노트는 BUILD + …). erect 노트의 BASIC은 "구조가 선 상태가 됨"으로 묶음의 "구조를 만든다"와 결과가 다르다.
