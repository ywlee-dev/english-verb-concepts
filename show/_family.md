# SHOW Family

## 상황에서 꺼내기 — 설명을 보기 전에

가상의 장면이다. **누구에게 무엇을 알 수 있게 하려는지**를 먼저 보자. 잠깐 제시하는지, 여러 사람이 보게 배치하는지, 특정 지점을 짚는지, 방법을 실제로 해 보이는지, 가려진 것을 드러내는지가 다르다.

1. 친구가 길을 몰라 지도를 펴서 보게 했다. 제시 방식은 특별히 강조하지 않는다. → ?
2. 학교 복도 게시판에 지도를 붙여 지나가는 사람들이 계속 볼 수 있게 했다. → ?
3. 친구가 보고 있는 지도에서 파란 산책로를 손가락으로 짚어 알려 주었다. → ?
4. 아이들이 매듭 그림만으로 이해하지 못해 안내자가 줄로 묶는 과정을 직접 해 보였다. → ?
5. 천 아래 가려 두었던 과학 모형을 발표 순간 처음 드러냈다. → ?

<details><summary>동사와 선택 이유 보기</summary>

1. **SHOW** — `I showed my friend the map.` 상대가 지도를 볼 수 있게 제시한다.
2. **DISPLAY** — `We displayed the map in the hallway.` 여러 사람이 볼 수 있게 배치한다.
3. **POINT OUT** — `I pointed out the trail on the map.` 이미 보이는 지도 안의 특정 요소에 주의를 모은다.
4. **DEMONSTRATE** — `The guide demonstrated the knot.` 실제 수행으로 방법을 보여 준다. 상대가 반드시 이해했다는 뜻은 아니다.
5. **REVEAL** — `We revealed the model by lifting the cloth.` 이전에 가려졌던 대상을 드러낸다.

</details>

**내 장면으로 바꿔 보기:** 최근 누군가에게 무언가를 보여 준 일을 떠올려 보자. 대상 전체, 공개 배치, 특정 부분, 수행 방법, 숨겨진 것의 공개 중 무엇이 핵심이었나?

## Shared Result

agent가 TARGET을 시야나 이해 가능한 증거로 제시하여 OBSERVER가 보거나 알 수 있게 한다.

| Verb | Example | Distinctive HOW |
|---|---|---|
| SHOW | show Mina the map | 대상이나 정보를 볼 수 있게 제시 |
| DISPLAY | display the map | 여러 사람이 잘 보도록 펼쳐 둠 |
| POINT OUT | point out the trail | 특정 대상을 지목해 주의를 이끎 |
| DEMONSTRATE | demonstrate the knot | 실제 동작으로 방법을 보여 줌 |
| REVEAL | reveal the hidden door | 가려졌던 것을 드러냄 |

## Scenario contrast

지도를 친구에게 내보이면 SHOW, 교실 앞에 펼쳐 모두가 보게 하면 DISPLAY, 지도 속 길을 손가락으로 짚으면 POINT OUT, 매듭 묶는 동작을 실행하면 DEMONSTRATE, 지도 뒤 숨은 문양을 드러내면 REVEAL이 된다.
