# START — cause to begin

## 0. Sound & Forms

- **Pronunciation (US):** /stɑːrt/ [**스타**트] — 단음절이다.
- **Forms:** `start` — `started` — `started`; 규칙 변화다.
- **시제와 결과:** `The team started the project on Monday morning.` → `The team has started the project. Work is now underway.` 시작시킨 동작과 현재 진행 중인 상태를 구별한다.

- **Sense:** 활동·과정·기계가 진행되는 상태가 되게 하다.
- **Example:** `The team started the project.`
- **Target Condition:** 대기·미진행 상태에서 진행 상태로 전환될 수 있는 활동·과정·시스템

## 언제 이 말을 꺼낼까?

팀에서 새 프로젝트를 준비만 하다가 월요일부터 실제 업무를 맡아 진행했다. **TARGET**은 프로젝트, 원하는 **RESULT**는 일이 더 이상 계획에만 머물지 않고 진행 중인 상태다. 첫 단계의 종류나 공개 행사는 강조하지 않는다.

- **내가 할 말:** `We started the project on Monday.`
- **BASIC/RESULT + HOW:** 미진행에서 진행으로 바뀜 + 시작 방식을 더 특정하지 않음 = `START`
- **선택 기준:** 일을 시작했다는 사실이면 `start`; 준비한 서비스를 사람들에게 공식 공개했다는 점이 중요하면 `launch`다.
- **한 번 더 떠올리기:** 설거지를 미루다가 이제 손을 댔다면? → `I started doing the dishes.`

## Scene Scenario
- **PLACE:** 월요일 아침의 팀 회의실
- **SITUATION / PROBLEM:** 계획은 준비됐지만 project 작업은 아직 진행되지 않았다.
- **PURPOSE:** 첫 업무를 배정해 실제 진행 상태로 바꾼다.
- **WHY THIS HOW?:** 공식 발표나 특정 장치보다 일반적인 시작 전환이 중요해 `START`가 선택된다.
- **ACTION → RESULT:** 팀장이 첫 업무를 배정하고 구성원들이 작업을 수행하기 시작한다.

```text
미진행 → 진행 상태 = START
```
