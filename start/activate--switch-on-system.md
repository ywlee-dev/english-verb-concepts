# ACTIVATE — switch a system into operation

## 0. Sound & Forms

- **Pronunciation (US):** /ˈæk.tɪ.veɪt/ [**액**티베이트] — 첫 음절 강세다.
- **Forms:** `activate` — `activated` — `activated`; 규칙 변화다.
- **시제와 결과:** `She activated the alarm system before leaving the science room.` → `She has activated the system. It can detect intruders now.` 신호를 준 동작과 현재의 작동 상태를 구별한다.

- **Sense:** 대기 중인 장치·기능·시스템에 신호를 주어 작동 상태로 만들다.
- **Example:** `She activated the alarm system.`
- **Target Condition:** 입력·스위치·조건에 의해 비활성 상태에서 작동 상태로 전환되는 시스템

## 언제 이 말을 꺼낼까?

집을 나서기 전 보안 센서는 설치되어 있지만 감시 기능이 꺼져 있다. **TARGET**은 보안 시스템, 원하는 **RESULT**는 침입을 감지할 준비가 된 작동 상태다. 코드를 입력해 그 기능을 켠다.

- **내가 할 말:** `I activated the alarm system before leaving.`
- **BASIC/RESULT + HOW:** 시스템이 작동 상태가 됨 + 코드로 기능을 켬 = `ACTIVATE`
- **선택 기준:** 준비된 기능을 활성 상태로 바꿀 때 `activate`. 경보가 실제로 울렸다는 뜻은 아니며, 그 사건은 별도로 말해야 한다.
- **한 번 더 떠올리기:** 휴대전화에서 비활성화된 위치 공유 기능을 켰다면? → `I activated location sharing.`

## Scene Scenario
- **PLACE:** 문을 닫기 직전의 과학실
- **SITUATION / PROBLEM:** alarm system은 설치되어 있지만 아직 감시 기능이 꺼져 있다.
- **PURPOSE:** 침입을 감지할 수 있는 작동 상태로 전환한다.
- **WHY THIS HOW?:** 기계적·전자적 기능을 신호로 켜는 전환이라 `ACTIVATE`가 선택된다.
- **ACTION → RESULT:** 보안 코드를 입력해 센서와 경보 기능을 활성 상태로 만든다.

```text
START + 시스템을 비활성에서 작동으로 전환 = ACTIVATE
```
