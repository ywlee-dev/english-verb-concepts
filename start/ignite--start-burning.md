# IGNITE — start burning

## 0. Sound & Forms

- **Pronunciation (US):** /ɪɡˈnaɪt/ [이그**나잇**] — 뒤 음절 강세다.
- **Forms:** `ignite` — `ignited` — `ignited`; 규칙 변화다.
- **시제와 결과:** `A spark ignited the fuel on the experiment table.` → `The spark has ignited the fuel. The fuel is burning steadily now.` 점화 순간과 현재 지속되는 연소 상태를 구별한다.

- **Sense:** 열·불꽃을 가해 물질이 타거나 연소 과정이 시작되게 하다.
- **Example:** `A spark ignited the fuel.`
- **Target Condition:** 충분한 열과 산소가 있으면 연소 반응을 시작할 수 있는 물질

## 언제 이 말을 꺼낼까?

안전하게 마련한 모닥불 자리에서 마른 불쏘시개는 아직 타지 않는다. 작은 불꽃이 닿자 불쏘시개에 불이 붙었다. **TARGET**은 불쏘시개, 원하는 **RESULT**는 물질이 실제로 연소하기 시작한 상태다.

- **내가 할 말:** `A spark ignited the kindling.`
- **BASIC/RESULT + HOW:** 타기 시작함 + 불꽃의 열이 연소를 일으킴 = `IGNITE`
- **선택 기준:** 물질에 불이 붙는 사건이면 `ignite`. 기계나 프로그램의 전원을 켠 사건이라면 보통 `activate`나 `start`가 맞는다.
- **한 번 더 떠올리기:** 성냥불이 종이에 옮겨 붙었다면? → `The match ignited the paper.`

## Scene Scenario
- **PLACE:** 안전 장비를 갖춘 과학 실험대
- **SITUATION / PROBLEM:** 소량의 fuel이 준비됐지만 아직 연소하지 않는다.
- **PURPOSE:** 연소 반응의 시작을 관찰한다.
- **WHY THIS HOW?:** 일반적인 작동이 아니라 불꽃으로 타기 시작하는 변화라 `IGNITE`가 선택된다.
- **ACTION → RESULT:** 불꽃이 fuel에 열을 전달하고 지속적인 연소가 시작된다.

```text
START + 열·불꽃으로 연소 개시 = IGNITE
```
