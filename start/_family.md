# START Family

## 상황에서 꺼내기 — 설명을 보기 전에

아래는 가상의 생활 장면이다. **무엇이 아직 시작되지 않았고**, 시작 후 **어떤 상태가 되는지**를 먼저 보자. 같은 장면에 `start`와 `begin`이 모두 자연스러울 수 있으므로 선택 이유를 함께 생각한다.

1. 월요일부터 팀의 새 프로젝트 일을 실제로 진행하기 시작했다. 시작 방식은 특별히 강조하지 않는다. → ?
2. 미뤄 둔 책을 오늘 첫 장부터 읽기 시작했다. 첫 부분에 들어간다는 느낌을 살리고 싶다. → ?
3. 학교가 준비한 독서 프로그램을 학생들에게 발표하고 신청을 받기 시작했다. → ?
4. 외출 직전 대기 중이던 보안 시스템에 코드를 입력해 감시 기능을 켰다. → ?
5. 모닥불의 마른 불쏘시개에 불꽃이 닿아 실제로 타기 시작했다. → ?

<details><summary>동사와 선택 이유 보기</summary>

1. **START** — `We started the project on Monday.` 미진행 상태에서 실제 진행 상태로 바뀌었다는 기본 사건이다.
2. **BEGIN** — `I began reading the book today.` 책 읽기의 첫 부분에 들어간다. 여기서 `started reading`도 자연스럽다.
3. **LAUNCH** — `The school launched a reading program.` 준비한 프로그램을 대외적으로 공개하며 운영을 시작한다.
4. **ACTIVATE** — `I activated the alarm system.` 스위치·코드로 시스템 기능을 대기 상태에서 작동 상태로 바꾼다. 경보음이 울렸다는 뜻은 아니다.
5. **IGNITE** — `A spark ignited the kindling.` 불꽃으로 연소가 시작된다. 단순히 장치의 전원을 켠 사건과 다르다.

</details>

**내 장면으로 바꿔 보기:** 오늘 시작한 일 하나를 떠올려 보자. 첫 단계에 들어간 것인지, 공식 공개인지, 장치 작동인지, 실제 연소인지 구별하면 동사가 떠오른다.

## Shared Result

아직 진행되지 않던 활동·과정·시스템이 진행되는 상태로 바뀐다.

| Verb | Example | Distinctive HOW / Context |
|---|---|---|
| START | start the project | 시작 방식 미지정 |
| BEGIN | begin the project | 첫 단계에 들어감에 초점 |
| LAUNCH | launch the project | 준비 후 공식적·공개적으로 시작 |
| ACTIVATE | activate the system | 신호·스위치로 작동 상태 전환 |
| IGNITE | ignite the fuel | 열·불꽃으로 연소 시작 |

## Scenario contrast

프로젝트가 진행되기 시작하면 START, 첫 작업에 들어가는 순간은 BEGIN, 대외 발표와 함께 공식 개시는 LAUNCH, 대기 중인 시스템에 신호를 주면 ACTIVATE, 연료에 불꽃을 주어 타게 하면 IGNITE가 된다. 대상의 종류와 시작 메커니즘이 HOW를 정한다.

`start`와 `begin`은 많은 문장에서 바꿔 쓸 수 있다. `begin`이 언제나 더 특별한 시작을 뜻하는 것은 아니다. 반면 `activate`는 시스템의 기능이 켜진 것이지 경보가 실제로 울렸다는 뜻은 아니며, `launch`도 준비 기간 전체를 뜻하지 않는다.
