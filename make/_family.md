# MAKE Family

## Shared Result

재료·정보·노력을 바꾸거나 결합하여 이전에 없던 결과물이나 준비된 상태를 만든다.

| Verb | Example | Distinctive HOW / Result |
|---|---|---|
| MAKE | make a model | 생성 방식 미지정 |
| CREATE | create a model | 아이디어·설계에서 새로운 결과를 창조 |
| PRODUCE | produce models | 반복 가능한 공정의 산출물로 생성 |
| PREPARE | prepare a model | 특정 사용·발표를 위해 준비된 상태로 만듦 |
| FORM | form a model from clay | 재료의 모양을 직접 바꿔 형성 |

## Scenario contrast

모형을 만든다는 결과만 말하면 MAKE, 독창적 설계에서 새 모형을 만들면 CREATE, 공정으로 여러 개를 출력하면 PRODUCE, 발표할 수 있게 점검·정리하면 PREPARE, 점토를 눌러 모양을 잡으면 FORM이 된다. 새로움·반복 공정·사용 목적·재료 변형이 HOW를 고른다.

`PREPARE`는 이미 만든 모형을 발표 가능한 상태로 만들 수 있어 새 결과물의 생성과는 다르다. 이 묶음은 넓은 '만들기/상태 만들기'를 학습용으로 비교한다.

## 상황에서 꺼내기 — 설명을 보기 전에

과학 시간에 모형을 다룬다. **새 물건이 생기는가, 기존 물건의 상태가 바뀌는가?**

1. 종이와 막대를 합쳐 태양계 모형 하나를 만든다. 설계의 독창성은 중요하지 않다.
2. 기존에 없는 물 절약 장치를 아이디어에서 설계해 모형으로 만든다.
3. 3D 프린터가 같은 설계 파일로 여러 조의 모형을 출력한다.
4. 이미 있는 모형의 느슨한 부분을 고정하고 표지를 붙여 발표 준비를 마친다.
5. 점토 덩어리를 누르고 굴려 행성의 둥근 모양을 만든다.

<details><summary>동사와 선택 이유 보기</summary>

1. `We made a model.` — 결과물이 생겼다는 넓은 표현이다.
2. `We created a new model.` — 새로운 아이디어를 실체화한다.
3. `The printer produced three models.` — 공정의 산출물이 강조된다.
4. `We prepared the model for the presentation.` — 기존 모형을 쓸 준비 상태로 만든다.
5. `We formed a model from clay.` — 재료의 형태를 직접 잡는다.
