# CREATE — make something new

## 0. Sound & Forms

- **Pronunciation (US):** /kriˈeɪt/ [크리**에**이트] — 뒤 음절 강세다.
- **Forms:** `create` — `created` — `created`; 규칙 변화다.
- **시제와 결과:** `The students created a new model in the invention prep classroom.` → `The students have created the model. Their original idea has a physical form now.` 독창적으로 만든 사건과 현재의 실체화된 상태를 구별한다.

- **Sense:** 아이디어·상상·설계를 바탕으로 새롭고 독창적인 결과를 만들다.
- **Example:** `The students created a new model.`
- **Target Condition:** 설계 선택을 통해 이전과 다른 형태로 만들어질 수 있는 결과물

## 언제 이 말을 꺼낼까?

발명 대회에 기존에 없는 물 절약 장치가 필요하다. 학생들이 아이디어를 설계해 모형으로 나타낸다. **새로운 것을 구상해 실체화하면** `create`다.

- **TARGET:** 아이디어와 선택을 통해 새로 구성할 수 있는 모형·이야기·작품.
- **BASIC/RESULT + HOW:** 결과물이 생김 + **구상·설계를 바탕으로 새롭게 만드는** 방식. 완전히 세계 최초여야 할 필요는 없다.
- **선택 경계:** `make`는 넓은 제작, `create`는 새롭게 구성한 면을 부각한다.
- **한 문장:** `The students created a new model.`
- **내 장면:** 내 생각에서 출발해 만든 작품을 떠올려 보자.

## Scene Scenario
- **PLACE:** 발명 대회 준비 교실
- **SITUATION / PROBLEM:** 기존에 없는 물 절약 장치의 model을 스스로 설계해야 한다.
- **PURPOSE:** 새로운 아이디어를 실제 형태로 나타낸다.
- **WHY THIS HOW?:** 단순 제작보다 독창성과 새 설계가 핵심이라 `CREATE`가 선택된다.
- **ACTION → RESULT:** 문제를 해결할 구조를 생각하고 재료를 조합해 새로운 model을 완성한다.

```text
MAKE + 아이디어에서 새로운 결과 = CREATE
```
