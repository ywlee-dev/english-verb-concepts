# HOOK UP — connect equipment for use

## 0. Sound & Forms

- **Pronunciation (US):** /hʊk ʌp/ [훅**업**] — 구동사이며 뒤 단어 `up`에 강세가 있다.
- **Forms:** `hook up` — `hooked up` — `hooked up`; 규칙 변화다.
- **시제와 결과:** `Jin hooked up the speakers before the show backstage.` → `Jin has hooked up the speakers. They are ready to use now.` 배선을 마친 동작과 현재의 사용 가능 상태를 구별한다. 음악 재생은 별개다.

- **Sense:** 필요한 선이나 장치를 이어 장비를 실제로 쓸 수 있게 하다.
- **Example:** `Jin hooked up the speakers before the show.`
- **Target Condition:** 여러 선·전원·입출력이 맞아야 작동하는 장비
- **Precondition:** 연결할 장비와 선이 모두 준비돼 있다.

## 언제 이 말을 꺼낼까?

새 게임기를 TV에 연결하려는데 화면선과 전원선이 아직 빠져 있다. 두 선을 맞는 곳에 연결해 게임기를 사용할 준비를 마쳤다. **TARGET**은 게임기, 원하는 **RESULT**는 TV와 전원에 이어져 켜서 쓸 수 있는 상태다.

- **내가 할 말:** `I hooked up the game console to the TV.`
- **BASIC/RESULT + HOW:** 장비 사이 작동 경로가 생김 + 필요한 선을 연결해 사용 준비를 마침 = `HOOK UP`
- **선택 기준:** 단일 플러그를 꽂는 동작이면 `plug in`; 장비를 연결해 쓸 준비 전체를 구어적으로 말하면 `hook up`이다. 전원을 켜거나 게임을 시작했다는 뜻은 아니다.
- **한 번 더 떠올리기:** 새 스피커를 TV와 전원에 연결했다면? → `I hooked up the speakers to the TV.`

## Scene Scenario
- **PLACE:** 공연 전 학교 무대 뒤
- **SITUATION / PROBLEM:** 스피커는 아직 전원과 음향 기기에 연결되지 않았다.
- **PURPOSE:** 공연 시작 전에 소리를 낼 수 있게 한다.
- **WHY THIS HOW?:** 하나의 접점보다 장비 전체를 실제 사용 상태로 연결하는 구어적 장면이라 `HOOK UP`이 자연스럽다.
- **ACTION → RESULT:** Jin이 전원선과 음향선을 차례로 이어 음악이 스피커에서 나온다.

```text
CONNECT + 여러 장비를 사용 가능하도록 배선 = HOOK UP
```

## Minimal Contrast

한 선을 꽂으면 `plug in`, 장비 전체를 연결해 쓸 준비를 하면 `hook up`한다.
