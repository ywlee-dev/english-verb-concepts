# FIND Family

## Shared Result

## 상황에서 꺼내기 — 설명을 보기 전에

잃어버린 열쇠를 찾는 과정의 어느 지점인지 먼저 상상해 보자.

1. 의자 다리 옆에서 열쇠를 보았다.
2. 분실물 기록으로 열쇠가 B-12 상자에 있다고 특정했다.
3. 처음 보는 비밀 서랍에서 열쇠의 존재를 알았다.
4. 여러 사람의 말과 이동 경로를 따라가 끝내 열쇠를 찾아냈다.
5. 손이 닿지 않던 틈에서 열쇠를 꺼내 되찾았다.

<details><summary>동사와 선택 이유 보기</summary>

1. `find`: I found the key by the chair. 모름에서 알아냄으로 바뀐다.
2. `locate`: I located the key in box B-12. 정확한 위치에 초점을 둔다.
3. `discover`: I discovered a hidden key in the drawer. 전에는 몰랐던 존재를 알게 된다.
4. `track down`: I tracked down the missing key. 단서를 추적해 찾아낸다.
5. `recover`: I recovered the key from under the cabinet. 잃었던 물건을 실제로 되찾는다.

</details>

내 장면으로 바꿔 보기: 최근 못 찾던 물건이나 정보를 떠올려, 위치만 알았는지 실제로 되찾았는지 구별해 보자.

agent가 이전에는 위치·정체·존재를 몰랐던 TARGET을 알아내어 접근 가능한 상태로 만든다.

| Verb | Example | Distinctive HOW |
|---|---|---|
| FIND | find the key | 잃거나 몰랐던 대상을 알아냄 |
| LOCATE | locate the key | 체계적으로 정확한 위치를 확인 |
| DISCOVER | discover a hidden key | 존재 자체를 처음 알아냄 |
| TRACK DOWN | track down the key | 단서를 이어 끝까지 찾아냄 |
| RECOVER | recover the key | 잃었던 대상을 다시 손에 넣음 |

## Scenario contrast

열쇠를 찾아내면 FIND, 교실 지도를 따라 정확한 위치를 확인하면 LOCATE, 비밀 서랍의 열쇠 존재를 처음 알면 DISCOVER, 발자국과 목격 단서를 따라가 찾아내면 TRACK DOWN, 찾은 열쇠를 틈에서 꺼내 다시 가지면 RECOVER이다.
