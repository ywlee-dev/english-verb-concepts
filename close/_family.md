# CLOSE Family

## 상황에서 꺼내기 — 설명을 보기 전에

아래는 가상의 생활 장면이다. 먼저 **무엇을 막으려는지(TARGET과 결과)**, **어떤 방식으로 막는지(HOW)**를 보고 동사를 떠올려 보자. 하나의 장면에 여러 동사가 가능할 수 있으므로, 단어 하나를 맞히는 것보다 선택 이유가 중요하다.

1. 장을 보고 돌아와 열려 있던 냉장고 문을 평소처럼 닫았다. 방식보다 열린 상태가 끝났다는 사실을 말하고 싶다. → ?
2. 차가 출발하기 전 문을 끝까지 밀어 확실히 닫았다. 완전히 맞닿게 한 동작을 강조하고 싶다. → ?
3. 비를 맞을 택배 상자의 이음새마다 테이프를 붙여 물이 스며들 틈을 막았다. → ?
4. 약상자는 이미 닫혀 있다. 아이가 열지 못하도록 열쇠를 돌려 고정했다. → ?
5. 보관 중인 책 위에 천을 씌워 먼지가 직접 닿지 않게 했다. → ?

<details><summary>정답과 선택 이유 보기</summary>

1. **CLOSE** — 냉장고 문을 닫아 접근 가능한 열린 상태를 끝낸다. HOW를 더 특정하지 않는다.
2. **SHUT** — 문을 끝까지 맞닿게 닫는 동작을 강조한다. 이 장면에도 `close the door`는 자연스럽지만, `shut`을 쓰면 확실한 닫힘에 초점이 간다.
3. **SEAL** — 상자를 단순히 닫는 것을 넘어 틈을 막아 물의 통과를 차단한다.
4. **LOCK** — 닫힌 약상자를 잠금장치로 고정해 허가 없는 개방을 막는다. `lock`만으로 매번 '닫는 동작'까지 뜻하는 것은 아니다.
5. **COVER** — 책의 구조를 닫는 것이 아니라 별도의 천으로 표면 노출을 막는다.

</details>

**내 장면으로 바꿔 보기:** 오늘 실제로 무엇을 닫거나, 잠그거나, 덮었는지 하나만 떠올려 영어 문장을 만들어 보자. 그때 막으려던 것이 **열림·틈·무단 개방·표면 노출** 중 무엇이었는지 말할 수 있으면 동사 선택도 쉬워진다.

## Shared Result

열려 있거나 노출된 통로·용기·내용에 대한 접근이나 통과를 막는다.

| Verb | Example | Distinctive HOW / Purpose |
|---|---|---|
| CLOSE | close the box | 닫는 방식 미지정 |
| SHUT | shut the box | 움직이는 부분을 완전히 맞닿게 닫음 |
| SEAL | seal the box | 틈을 막아 공기·물질 통과 방지 |
| LOCK | lock the box | 잠금장치로 허가 없는 개방 방지 |
| COVER | cover the box | 다른 물체를 위에 놓아 노출 차단 |

## Scenario contrast

뚜껑을 닫는다는 결과만 말하면 CLOSE, 단단히 완전히 닫는 동작은 SHUT, 습기가 들어오지 않게 틈을 막으면 SEAL, 다른 사람이 열지 못하게 하면 LOCK, 먼지가 앉지 않도록 천을 위에 놓으면 COVER가 된다.
