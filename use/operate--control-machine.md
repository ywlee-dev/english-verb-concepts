# OPERATE — control a machine

## 0. Sound & Forms

- **Pronunciation (US):** /ˈɑː.pə.reɪt/ [**아**퍼레이트] — 첫 음절 강세다.
- **Forms:** `operate` — `operated` — `operated`; 규칙 변화다.
- **시제와 결과:** `Mina operated the printer in the computer room.` → `Mina has operated the printer. The picture is printed now.` 조작 절차를 수행한 사건과 현재의 출력 완료 상태를 구별한다.

- **Sense:** 정해진 조작으로 기계나 시스템을 작동시키다.
- **Example:** `Mina operated the printer.`
- **Target Condition:** 입력 장치와 절차를 통해 기능을 켜고 조절할 수 있는 기계
- **Precondition:** 기계에 전원과 필요한 재료가 있고 agent가 조작법을 안다.

## 언제 이 말을 꺼낼까?

컴퓨터실에서 프린터의 용지를 선택하고 출력 버튼을 누른다. TARGET은 프린터·카메라·기계처럼 조작을 통해 기능을 작동시킬 수 있는 것이다. `OPERATE = 기계를 작동시키는 기본 사건 + 제어 절차를 수행하는 HOW`. `operate` 자체가 출력물의 완성을 보장하는 것은 아니다. `Mina operated the printer.` 내가 조작할 줄 아는 기계를 넣어 말해 보자.

## Scene Scenario
- **PLACE:** 학교 컴퓨터실 프린터 앞
- **SITUATION / PROBLEM:** 참고 사진을 인쇄하려면 용지 선택과 출력 버튼 조작이 필요하다.
- **PURPOSE:** 프린터가 원하는 사진을 출력하게 한다.
- **WHY THIS HOW?:** 단순 활용보다 기계의 제어 절차를 직접 수행하므로 `OPERATE`가 정확하다.
- **ACTION → RESULT:** Mina가 파일과 용지를 선택하고 출력 버튼을 눌러 프린터가 사진을 만든다.

```text
USE + 제어 절차로 기계를 작동 = OPERATE
```

## Minimal Contrast

프린터를 과제에 `use`하고, 버튼과 설정으로 프린터를 `operate`한다.
