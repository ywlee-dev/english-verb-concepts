# REUSE — use again

## 0. Sound & Forms

- **Pronunciation (US):** /ˌriːˈjuːz/ [리**유**즈] — 뒤 음절 강세다.
- **Forms:** `reuse` — `reused` — `reused`; 규칙 변화다.
- **시제와 결과:** `Mina reused the box for her paints during cleanup.` → `Mina has reused the box. It holds her paint containers now.` 다시 활용한 사건과 현재의 새 용도 상태를 구별한다.

- **Sense:** 이미 한 번 사용한 TARGET을 버리지 않고 같은 목적이나 새 목적으로 다시 쓰다.
- **Example:** `Mina reused the box for her paints.`
- **Target Condition:** 첫 사용 뒤에도 기능이나 재료 가치가 남아 있는 대상
- **Precondition:** TARGET의 원래 사용은 끝났지만 다시 활용할 수 있는 상태다.

## 언제 이 말을 꺼낼까?

택배 상자를 버리지 않고 물감 통을 담는 상자로 다시 쓴다. TARGET은 상자·병·종이처럼 한 번 쓴 뒤에도 기능이나 재료가 남은 것이다. `REUSE = 수단으로 활용하는 기본 사건 + 이미 사용한 것을 다시 쓰는 HOW`. 반드시 새로운 용도여야 하는 것은 아니다. `I reused the box for my paints.` 오늘 다시 쓴 물건이 있으면 넣어 보자.

## Scene Scenario
- **PLACE:** 미술 교실 정리 시간
- **SITUATION / PROBLEM:** 빈 종이 상자를 버릴 수 있지만 물감들이 책상에 흩어져 있다.
- **PURPOSE:** 새 보관함을 사지 않고 물감을 정리한다.
- **WHY THIS HOW?:** 사용이 끝난 상자에 두 번째 기능을 부여하므로 단순 `USE`보다 `REUSE`가 정확하다.
- **ACTION → RESULT:** Mina가 상자의 라벨을 떼고 물감 통을 넣어 보관함으로 다시 사용한다.

```text
USE + 사용이 끝난 대상을 다시 활용 = REUSE
```

## Minimal Contrast

새 상자를 처음 `use`할 수 있고, 빈 상자를 다른 목적으로 `reuse`할 수 있다.
