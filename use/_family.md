# USE Family

## Shared Result

## 상황에서 꺼내기 — 설명을 보기 전에

그림을 완성하고 교실을 정리하는 장면이다. 무엇을 어떤 수단으로 썼는지 골라 보자.

1. 태블릿을 참고 사진 찾는 도구로 삼는다.
2. 프린터의 설정과 버튼을 조작한다.
3. 물감을 종이 표면에 바른다.
4. 색칠에 10분을 쓴다.
5. 쓰고 남은 상자를 물감 보관함으로 다시 쓴다.

<details><summary>동사와 선택 이유 보기</summary>

1. `use`: I used the tablet to find a picture. 기능을 목적에 활용한다.
2. `operate`: I operated the printer. 기계를 조작한다.
3. `apply`: I applied paint to the paper. 물질을 표면에 직접 옮긴다.
4. `spend`: I spent ten minutes coloring. 제한된 시간을 투입한다.
5. `reuse`: I reused the box for my paints. 이미 쓴 것을 다시 활용한다.

</details>

내 장면으로 바꿔 보기: 오늘 사용한 도구 하나와 그 일에 쓴 시간 하나를 영어로 말해 보자.

agent가 TARGET의 기능이나 가치를 특정 목적을 이루는 수단으로 작동시킨다.

| Verb | Example | Distinctive HOW |
|---|---|---|
| USE | use the tablet | 기능을 목적에 활용 |
| OPERATE | operate the tablet | 조작 절차로 기계를 작동 |
| APPLY | apply the paint | 물질·규칙을 대상에 직접 작용시킴 |
| SPEND | spend ten minutes | 시간·돈을 사용해 잔량을 줄임 |
| REUSE | reuse the box | 이미 쓴 대상을 다시 활용 |

## Scenario contrast

태블릿을 조사 도구로 활용하면 USE, 버튼과 화면을 조작해 작동시키면 OPERATE, 붓으로 물감을 표면에 바르면 APPLY, 작업에 10분을 쓰면 SPEND, 빈 상자를 보관함으로 다시 쓰면 REUSE이다.
