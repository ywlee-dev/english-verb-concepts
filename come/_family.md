# COME Family

## 상황에서 꺼내기 — 설명을 보기 전에

가상의 장면이다. **기준점이 어디인지**, 목적지에 도달했는지, 이전에 있던 곳으로 돌아오는지, 경계를 넘었는지를 보자. 이 묶음은 관련 이동 사건을 비교하는 학습용 틀이며 모든 동사가 화자 쪽 방향을 뜻하지는 않는다.

1. 친구가 카페에서 기다리고 있고 나는 그쪽으로 이동한다. 친구가 있는 곳을 기준으로 말한다. → ?
2. 기차역으로 가는 여정이 끝나 실제로 역에 도착했다. → ?
3. 집에 있다가 외출한 뒤 다시 집으로 왔다. → ?
4. 멀리 있던 개가 내 쪽으로 점점 가까워진다. 내 앞까지 왔는지는 모른다. → ?
5. 도서관 문턱을 넘어 건물 안으로 들어갔다. → ?

<details><summary>동사와 선택 이유 보기</summary>

1. **COME** — `I'm coming to the cafe.` 친구가 있는 기준점 쪽으로 이동한다.
2. **ARRIVE** — `I arrived at the station.` 목적지에 도달했다. 화자 쪽 방향은 필수가 아니다.
3. **RETURN** — `I returned home.` 이전에 있던 장소로 다시 갔다. `return`도 화자 쪽 방향을 필수로 하지 않는다.
4. **APPROACH** — `The dog approached me.` 거리가 줄어든다. 도착이나 접촉은 보장하지 않는다.
5. **ENTER** — `I entered the library.` 외부에서 내부로 경계를 넘었다.

</details>

**내 장면으로 바꿔 보기:** 최근 이동 하나를 떠올려 보자. 누군가 있는 쪽으로 가는지, 도달했는지, 되돌아왔는지, 가까워지는 중인지, 안으로 들어갔는지 구분한다.

## Shared Event Backbone

움직이는 주체가 화자·기준 인물·기준 장소 쪽으로 가까워진다.

| Verb | Example | Distinctive Path / Result |
|---|---|---|
| COME | The child came to school. | 기준 장소 쪽 이동 |
| ARRIVE | The child arrived at school. | 목적지 도달 완료 |
| RETURN | The child returned to school. | 이전에 있던 장소로 다시 옴 |
| APPROACH | The child approached the school. | 더 가까워지지만 도달은 보장하지 않음 |
| ENTER | The child entered the school. | 경계를 넘어 내부로 들어옴 |

```text
COME + 목적지 도달 완료       = ARRIVE
COME + 이전 장소로 다시 이동  = RETURN
COME + 거리를 줄이며 가까워짐  = APPROACH
COME + 경계를 넘어 내부로 이동 = ENTER
```

## Scenario contrast

교사가 학교에서 학생에게 이쪽으로 오라고 하면 COME, 등교 여정이 끝났음을 말하면 ARRIVE, 집에 갔다가 다시 학교로 오면 RETURN, 학교 건물 가까이 다가가면 APPROACH, 문을 넘어 건물 안으로 들어가면 ENTER가 된다. 기준점·도달 여부·이전 위치·경계가 차이를 만든다.

`ARRIVE`, `RETURN`, `APPROACH`, `ENTER`가 문법적으로 언제나 `COME`을 포함하는 것은 아니다. 특히 `arrive`는 도달, `enter`는 경계 통과를 말하므로 화자 쪽 이동인지 여부는 문맥에 달려 있다.

## Sound & Forms reference

`come → came → come`은 불규칙 변화다. `arrive`, `return`, `approach`, `enter`는 규칙 변화다. `approach`는 가까워짐이지 도착을 보장하지 않는다. 발음·형태 확인: [Cambridge: come](https://dictionary.cambridge.org/us/dictionary/english/come), [arrive](https://dictionary.cambridge.org/us/pronunciation/english/arrive), [return](https://dictionary.cambridge.org/us/pronunciation/english/return), [approach](https://dictionary.cambridge.org/us/pronunciation/english/approach), [enter](https://dictionary.cambridge.org/us/pronunciation/english/enter).
