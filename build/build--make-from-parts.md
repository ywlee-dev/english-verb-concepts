# BUILD — make from parts

## 0. Sound & Forms

- **Pronunciation (US):** /bɪld/ [**빌**드] — 단음절이다.
- **Forms:** `build` — `built` — `built`; 불규칙 변화다.
- **시제와 결과:** `The students built a shelter on the school field.` → `The students have built the shelter. It can shade people from the sun now.` 부품을 결합한 사건과 현재의 사용 가능한 구조 상태를 구별한다.

- **Sense:** 재료와 부품을 결합해 지속되는 구조나 시스템을 만들다.
- **Example:** `The students built a shelter.`
- **Target Condition:** 여러 부분이 관계에 맞게 결합되어 전체 구조가 될 수 있는 대상

## 언제 이 말을 꺼낼까?

야외 수업에서 햇빛을 피할 곳이 없다. 학생들이 막대를 연결하고 천을 씌워 대피소를 만든다. **부품이 하나의 구조를 이루면** `build`다.

- **TARGET:** 여러 부분을 결합해 세울 수 있는 대피소·집·가구.
- **BASIC/RESULT + HOW:** 전체 구조가 생김 + 구체적인 시공 절차는 **특정하지 않는** 방식.
- **선택 경계:** `make`는 결과물 생성의 넓은 말; `build`는 부분들의 구조적 결합이 보인다.
- **한 문장:** `The students built a shelter on the field.`
- **내 장면:** 여러 부품으로 만든 구조물을 떠올려 보자.

## Scene Scenario
- **PLACE:** 학교 운동장의 야외 생존 수업
- **SITUATION / PROBLEM:** 햇빛을 피할 shelter가 없고 나무 막대와 천이 있다.
- **PURPOSE:** 사람이 들어갈 수 있는 구조를 만든다.
- **WHY THIS HOW?:** 단일 물체 제작보다 여러 부품의 지속적 구조 결합이 중요해 `BUILD`가 선택된다.
- **ACTION → RESULT:** 막대를 연결하고 천을 씌워 서 있는 shelter를 만든다.

```text
MAKE + 부품을 구조로 결합 = BUILD
```
