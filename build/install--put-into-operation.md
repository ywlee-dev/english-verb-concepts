# INSTALL — put into operation

## 0. Sound & Forms

- **Pronunciation (US):** /ɪnˈstɔːl/ [인**스톨**] — 뒤 음절 강세다.
- **Forms:** `install` — `installed` — `installed`; 규칙 변화다.
- **시제와 결과:** `They installed a heater in the shelter for the winter.` → `They have installed the heater. It is running now.` 배치·연결한 사건과 현재의 작동 상태를 구별한다.

- **Sense:** 장비·부품을 필요한 위치에 배치하고 연결해 사용할 수 있게 하다.
- **Example:** `They installed a heater in the shelter.`
- **Target Condition:** 위치 고정과 전원·배관·시스템 연결 후 기능할 수 있는 장비

## 언제 이 말을 꺼낼까?

난방기는 이미 상자 안에 있다. 대피소에서 위치를 정하고 필요한 연결을 해 사용할 수 있게 한다. **기존 장비를 제자리에 설치하면** `install`이다.

- **TARGET:** 적절한 위치·연결이 있어야 쓸 수 있는 난방기·조명·프로그램.
- **BASIC/RESULT + HOW:** 기존 장비가 배치·연결되어 사용 가능한 상태가 됨 + **환경 안에 설치하는** 방식. 새로 만든 것은 아니다.
- **선택 경계:** 대피소 자체를 `build`하고 그 안에 장비를 `install`한다. 설치가 곧 실제 작동을 보장하지는 않는다.
- **한 문장:** `They installed a heater in the shelter.`
- **내 장면:** 집이나 컴퓨터에 설치한 물건·프로그램을 떠올려 보자.

## Scene Scenario
- **PLACE:** 겨울 임시 대피소 내부
- **SITUATION / PROBLEM:** heater는 상자에서 꺼냈지만 전원과 배기 연결이 없어 사용할 수 없다.
- **PURPOSE:** 장비를 안전하게 작동 가능한 상태로 만든다.
- **WHY THIS HOW?:** 물건을 만드는 것이 아니라 기존 장비를 환경에 연결해 사용 가능하게 하므로 `INSTALL`이 선택된다.
- **ACTION → RESULT:** heater를 고정하고 전원·배기구를 연결해 작동시킨다.

```text
BUILD + 장비 배치·연결로 사용 가능 = INSTALL
```
