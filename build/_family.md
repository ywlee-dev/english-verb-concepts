# BUILD Family

## Shared Result

여러 부품·재료를 관계에 맞게 결합하여 지속되는 구조나 작동 가능한 전체를 만든다.

| Verb | Example | Distinctive HOW |
|---|---|---|
| BUILD | build a shelter | 구조 생성 방식 미지정 |
| CONSTRUCT | construct a shelter | 도면·순서에 따라 체계적으로 시공 |
| ASSEMBLE | assemble a shelter | 준비된 부품을 맞춰 결합 |
| ERECT | erect a shelter | 눕거나 분리된 구조를 세워 올림 |
| INSTALL | install the shelter equipment | 위치에 배치·연결해 사용 가능하게 함 |

## Scenario contrast

대피소 구조를 만들면 BUILD, 도면과 공정에 따라 시공하면 CONSTRUCT, 미리 만든 패널을 조립하면 ASSEMBLE, 기둥과 천막을 세워 올리면 ERECT, 난방 장비를 연결해 사용할 수 있게 하면 INSTALL이 된다. 부품 준비 상태·방향·사용 연결이 HOW를 결정한다.

`INSTALL`은 이미 존재하는 장비를 제자리에 연결해 쓰게 만드는 사건이라, 새 구조를 짓는 `BUILD`와 엄격히 같은 결과는 아니다. 이 패밀리는 설치까지 이어지는 구조물 준비를 학습용으로 비교한다.

## 상황에서 꺼내기 — 설명을 보기 전에

임시 대피소를 마련한다. **재료·부품·구조·장비 중 무엇을 다루는가?**

1. 막대와 천을 결합해 햇빛을 피할 구조를 만든다.
2. 안전 기준에 맞는 도면과 순서대로 대피소를 시공한다.
3. 미리 만들어진 벽·지붕 패널을 번호에 맞춰 연결한다.
4. 바닥에 누운 골조를 들어 올려 수직으로 고정한다.
5. 이미 만들어진 난방 장비를 대피소 안에 놓고 연결해 쓰게 한다.

<details><summary>동사와 선택 이유 보기</summary>

1. `We built a shelter.` — 구조물이 생긴 결과다.
2. `Workers constructed a shelter from a plan.` — 계획에 따른 체계적 시공이다.
3. `We assembled the shelter panels.` — 준비된 부품을 맞춘다.
4. `We erected the shelter frame.` — 구조가 위로 선다.
5. `We installed a heater in the shelter.` — 장비가 사용 가능한 자리에 놓인다. 장비를 새로 만든 것은 아니다.

</details>
