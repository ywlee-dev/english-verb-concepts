# SEND Family

## Shared Result

agent가 TARGET을 현재 위치에서 떨어진 수신자·목적지 쪽으로 출발시킨다. 수신 완료까지는 보장하지 않는다. 기존 `GIVE`는 상대에게 넘기는 관계, `BRING`은 기준점 쪽 이동이다.

| Verb | Example | Distinctive HOW |
|---|---|---|
| SEND | send a message | 발송 방식 미지정 |
| MAIL | mail a letter | 우편 경로로 발송 |
| EMAIL | email a message | 전자우편으로 발송 |
| TEXT | text a message | 휴대전화 문자로 발송 |
| FORWARD | forward a message | 받은 내용을 다른 사람에게 다시 발송 |

## Same-scene contrast

안내를 멀리 있는 사람에게 보내면 SEND, 종이 편지를 우체통에 넣으면 MAIL, 이메일 계정으로 보내면 EMAIL, 휴대전화 문자로 보내면 TEXT, 이미 받은 안내를 다른 친구에게 넘기면 FORWARD이다.

## 상황에서 꺼내기 — 설명을 보기 전에

친구 Jin에게 행사 변경 소식을 알려야 한다. **어떤 경로로 출발시키는가?**

1. 메시지를 보냈다는 사실만 전한다. 앱이나 매체는 중요하지 않다.
2. 손으로 쓴 편지를 봉투에 넣어 우체통에 맡긴다.
3. 계획표 파일을 첨부해 이메일 주소로 보낸다.
4. 버스 정류장에서 약속 시간이 바뀌었다는 짧은 글을 휴대전화로 보낸다.
5. 선생님에게 이미 받은 안내를 Jin에게 다시 전달한다.

<details><summary>동사와 선택 이유 보기</summary>

1. `I sent Jin a message.` — 발송 결과만 말한다. Jin이 읽었는지는 별도 확인이 필요하다.
2. `I mailed Jin a letter.` — 우편 경로를 쓴다.
3. `I emailed the plan to Jin.` — 이메일 경로를 쓴다.
4. `I texted Jin the new time.` — 휴대전화 메시지로 보낸다.
5. `I forwarded the teacher's message to Jin.` — 이미 받은 내용을 다음 사람에게 넘긴다.

</details>

**내 장면으로 바꿔 보기:** 오늘 누군가에게 보낸 정보 하나를 떠올려 경로를 정확히 말할지, 발송 사실만 말할지 고른다. 보냈다고 해서 상대가 읽었다고 단정하지 않는다.
