# GO Family

## 상황에서 꺼내기 — 설명을 보기 전에

가상의 생활 장면이다. **어디로 이동하는지**와 함께 **발의 움직임·자세·시간 압박** 중 무엇을 말하고 싶은지 보자. `rush`는 서두름을 말하지 반드시 뛰었다는 뜻은 아니다.

1. 집에서 가게로 이동했다. 걷거나 버스를 탔는지는 중요하지 않다. → ?
2. 시간이 충분해서 집에서 가게까지 두 발로 걸어갔다. → ?
3. 정류장의 버스를 놓치지 않으려고 정류장까지 빠르게 뛰었다. → ?
4. 약속에 늦어 기차역으로 급히 갔다. 뛰었는지 택시를 탔는지는 말하지 않는다. → ?
5. 탁자 아래로 굴러간 공을 찾으려고 몸을 낮춰 손과 무릎으로 들어갔다. → ?

<details><summary>동사와 선택 이유 보기</summary>

1. **GO** — `I went to the store.` 현재 위치를 떠나 다른 곳으로 이동한다. 방식은 미지정이다.
2. **WALK** — `I walked to the store.` 두 발로 걸어 이동한다. 걷는 속도가 반드시 느릴 필요는 없다.
3. **RUN** — `I ran to the bus stop.` 두 발로 빠르게 뛰어 이동한다.
4. **RUSH** — `I rushed to the station.` 시간 압박 때문에 서둘렀다. 이동 수단은 이 말만으로 알 수 없다.
5. **CRAWL** — `I crawled under the table to get the ball.` 몸을 낮추고 손·무릎 등을 써 이동한다.

</details>

**내 장면으로 바꿔 보기:** 오늘 어딘가로 이동했다면 이동 사실, 걷기, 뛰기, 서두름, 낮은 자세 중 무엇을 상대에게 꼭 전해야 하는지 골라 보자.

## Shared Event Backbone

움직이는 주체가 현재 위치를 떠나 다른 장소나 방향으로 이동한다.

| Verb | Same-subject example | Distinctive HOW / Situation |
|---|---|---|
| GO | The child went to the door. | 이동 방식 미지정 |
| WALK | The child walked to the door. | 보통 속도로 두 발을 번갈아 이동 |
| RUN | The child ran to the door. | 두 발이 순간적으로 지면에서 떨어지는 빠른 이동 |
| RUSH | The child rushed to the door. | 시간 압박과 긴급성을 동반한 빠른 이동 |
| CRAWL | The child crawled to the door. | 몸을 낮추고 손·무릎 등을 사용 |

```text
GO + 보통 속도로 두 발 이동 = WALK
GO + 빠르게 두 발 이동      = RUN
GO + 긴급성과 시간 압박      = RUSH
GO + 몸을 낮춰 이동          = CRAWL
```

## Scenario contrast

교실에서 문으로 이동한다는 사실만 중요하면 GO, 복도를 두 발로 이동하면 WALK, 닫히기 전에 빠르게 뛰면 RUN, 시간에 쫓겨 급히 가면 RUSH, 낮은 공간을 손·무릎으로 지나가면 CRAWL이 된다. 속도·긴급성·신체 자세가 HOW를 고른다. `walk`는 반드시 느린 속도가 아니고, `rush`는 반드시 달리기를 뜻하지 않는다.

## Sound & Forms reference

`go → went → gone`, `run → ran → run`은 불규칙 변화다. `walk`, `rush`, `crawl`은 규칙 변화다. `walk`의 `l`은 묵음이다. 발음·형태 확인: [Cambridge: go](https://dictionary.cambridge.org/us/dictionary/english/go), [walk](https://dictionary.cambridge.org/us/pronunciation/english/walk), [run](https://dictionary.cambridge.org/us/dictionary/english/run), [rush](https://dictionary.cambridge.org/us/pronunciation/english/rush), [crawl](https://dictionary.cambridge.org/us/pronunciation/english/crawl).
