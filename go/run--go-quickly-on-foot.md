# RUN — go quickly on foot

## 0. Sound & Forms

- **Pronunciation (US):** /rʌn/ [런] — 과거 `ran` /ræn/에서는 모음이 달라진다.
- **Forms:** `run` — `ran` — `run`; 과거분사는 다시 `run`이다.
- **시제와 결과:** `The child ran to the gym door before it closed.` → `The child has run to the door. He reached it in time.` 빠른 두 발 이동을 나타낸다.

- **Sense:** 두 발이 순간적으로 모두 지면에서 떨어지는 빠른 걸음으로 이동하다.
- **Example:** `The child ran to the door.`
- **Target Condition:** 다리로 빠르게 몸을 추진하고 균형을 유지할 수 있는 주체

## 언제 이 말을 꺼낼까?

정류장에 버스가 와 있다. 늦지 않으려고 정류장까지 두 발로 빠르게 뛰었다. **TARGET**은 이동하는 나, 원하는 **RESULT**는 정류장에 빨리 도달한 상태다. 시간 압박뿐 아니라 실제로 뛰었다는 움직임을 말한다.

- **내가 할 말:** `I ran to the bus stop.`
- **BASIC/RESULT + HOW:** 정류장 쪽으로 이동함 + 두 발로 빠르게 뜀 = `RUN`
- **선택 기준:** 달린 동작이 핵심이면 `run`; 급히 갔지만 어떻게 이동했는지 모르면 `rush`가 가능하다.
- **한 번 더 떠올리기:** 비를 피해 집까지 뛰었다면? → `I ran home to get out of the rain.`

## Scene Scenario
- **PLACE:** 방과 후 넓고 비어 있는 체육관
- **SITUATION / PROBLEM:** 문이 곧 닫히며 아이와 문 사이에 장애물이 없다.
- **PURPOSE:** 닫히기 전에 문에 도착한다.
- **WHY THIS HOW?:** 걷기보다 빠른 발 이동이 필요하지만 공포 상황은 아니므로 `RUN`이 자연스럽다.
- **ACTION → RESULT:** 다리로 연속해서 몸을 밀어 빠르게 문까지 이동한다.

```text
GO + 빠른 두 발 이동 = RUN
```
